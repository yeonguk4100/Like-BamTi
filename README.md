## 실행하기

터미널에서 순서대로 입력합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 **http://localhost:3000** 을 엽니다.

## MVP 범위 (확정 화면 3개)

**필수 — 이번에 만든다**
1. 사진 올리기 — 욕실·현관·복도 3~5장
2. AI 위험 판정 — 정부 13개 지원품목 기준으로 손잡이 부재·단차·조명·바닥
3. 받을 수 있는 복지사업 목록 + 총 예상 지원액

**나중** — 신청서 자동 채움 / 시공 후 재촬영·전후 비교 / 기관용 대시보드 / 로그인·결제

**버림** — 치수 실측(시공업체가 함) / AI 챗봇·대화(클로바 케어콜과 충돌) / 서류 대신 작성·제출(⚖️ 행정사법) / 업체 리드 판매(⚖️ 알선 금지)
