# public/

브라우저가 `/` 경로로 바로 받는 정적 파일 자리다.

| 파일 | 쓰이는 곳 | 상태 |
|---|---|---|
| `hero-illustration.png` | 안내 띠 삽화 (`app/components/HeroArt.tsx`) | 1448×1086 · 756KB · 배경 투명 |

## hero-illustration.png

담당자와 학부모가 한 화면을 함께 보는 삽화. **가로 720px 이상**을 권한다
(화면에서 최대 352px 로 그려지므로 2배수). 바꿀 때 파일 이름을 그대로 쓰면 코드는 손대지 않아도 된다.

**없어도 화면은 깨지지 않는다.** `HeroArt` 가 로드 실패를 감지해 삽화 자리를
통째로 지우고, 글이 그만큼 폭을 되찾는다. 깨진 이미지 아이콘이 뜨지 않는다.

배경이 흰색이거나 투명이어도 된다 — 남색 띠 위에 흰 패널을 깔아 얹는다.
