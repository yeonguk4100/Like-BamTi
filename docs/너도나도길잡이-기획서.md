# 너도나도 길잡이

**특수교육 지원제도 상담 지원 도구 — 담당자가 학부모 문의를 3분에 끝내게 하는 B2G 업무 도구**

업무 효율화 트랙 · 2026.08 고도화판

> 기관 담당자가 학부모 문의를 받았을 때 아동의 **거주지·장애영역·생년월일·학교급**을 입력하면, 확인해야 할 제도와 **제출 서류·필수 검사·마감일·근거 법령**을 한 장으로 정리해 주고, **학부모에게 그대로 건넬 안내문**까지 함께 만들어 주는 도구.

> **이름에 대하여** — 강원특별자치도교육청이 담당자에게 배포하는 공식 문서의 제목이 「특수교육대상자 선정·배치 업무 **길잡이**」입니다. 담당자가 이미 쓰는 말을 그대로 가져왔습니다. **「너도나도」**는 담당자와 학부모가 같은 한 장을 본다는 뜻입니다 — 이 도구는 한 번 입력해 **두 사람 몫의 문서**를 만듭니다 (4.1).

**이 판에서 달라진 것** — 강원·경남 두 시도교육청의 선정·배치 지침 원문을 대조해, 추정으로 적었던 절차·기한·지역 차이를 **1차 자료로 교체**했습니다. 그 과정에서 문제 정의가 하나 넓어졌고(1.3, 1.4), **사업 구조를 B2G로 명확히 했습니다**(6장).

## 0. 한 화면 요약

### 무엇이 문제인가

아이에게 장애가 있다는 것을 막 알게 된 부모는 **무엇부터 해야 하는지 모릅니다.** 그래서 기관에 전화합니다. 그런데 전화를 받은 담당자도 **전부를, 그리고 지금 기준으로는 알기 어렵습니다.**

세 겹으로 갈라져 있기 때문입니다.

| 무엇이 갈라져 있나 | 근거 |
|---|---|
| **부처가 갈려 있다** — 교육·복지·의료·고용 | 1.2 |
| **같은 교육청 안에서도 담당자가 갈려 있다** | **강원도교육청 지침 원문** (1.3) |
| **제도 이름이 지역마다 다르고, 시간이 지나면 또 바뀐다** | **6개 시도 카드 명칭 대조** (1.4) |

### 누가 쓰고, 누가 돈을 내는가 — **B2G2C**

| | 누구 | 무엇을 | 성격 |
|---|---|---|---|
| **구매자** | **시도교육청 / 교육지원청** | 도입 결정과 예산 집행 | **B2G** |
| **사용자** | 기관 담당자 (특수교육지원센터·복지관·가족지원센터) | 상담하면서 조건을 입력 | **B2G** |
| **수혜자** | 학부모 | 개인화된 안내문을 받음 | **2C (무료)** |
| **최종 수혜자** | 아동 | 되돌릴 수 없는 시기를 놓치지 않음 | — |

> **B2B가 아니라 B2G입니다.** 구매자가 기업이 아니라 공공기관이라 **지방계약법을 타는 조달 절차**를 거칩니다. 그리고 교육청 조직은 **위탁이 아니라 직할**이라, 한 번 도입되면 산하 교육지원청 전체가 사용자가 됩니다 (6.1).

### 무엇을 하는 도구인가

**판정하지 않습니다. 확인 목록을 줍니다. 그리고 개인정보를 저장하지 않습니다.**

```
담당자가 상담 중 조건 입력  ─┬─▶ ① 담당자용 확인 시트
 (거주지·장애영역·생년월일·학교급)  └─▶ ② 학부모용 안내문
```

### 해결하면 무엇이 달라지나

| 누구 | 지금 | 도구가 있으면 |
|---|---|---|
| **담당자** | 소관 밖 문의를 그 자리에서 검색해 답한다 | **확인 목록이 근거와 함께 한 번에 나온다** |
| **학부모** | 기관마다 다른 말을 듣고 다시 전화한다 | **무엇을·어디에·언제까지 내야 하는지 종이 한 장으로 받는다** |
| **아동** | 재선정 시기를 놓치면 받던 지원이 끊긴다 | **날짜가 있는 마감을 미리 안다** |
| **기관** | 안내가 담당자마다 다르고 기록이 안 남는다 | **무엇을 안내했는지 근거와 함께 남는다** |

## 1. 문제 정의

### 1.1 전 과정이 신청주의다

일반 아동은 제도가 자동으로 작동합니다. 취학통지서가 오고, 배정되고, 졸업하면 상급학교로 넘어갑니다.

특수교육 대상은 정반대입니다. 진단·평가, 배치, 발달재활, 방과후활동 — 전 과정이 신청주의이고, **신청해야 한다는 사실을 알려주는 주체가 없습니다.**

그리고 **한 번 받았다고 끝나지 않습니다.** 발달지체는 만 9세 전에, 건강장애는 매년 다시 신청해야 합니다 (2.3).

### 1.2 부처가 네 갈래로 갈려 있다

| 영역 | 소관 | 신청처 |
|---|---|---|
| 진단·평가, 학교 배치, 치료지원 | **교육청** | 특수교육지원센터 |
| 장애 진단·등록 | 복지부 (의료기관 경유) | 병원 → 읍면동 |
| 발달재활, 방과후활동, 주간활동 | 복지부 | 읍면동 / 발달장애인지원센터 |
| 취업·직업재활 | 고용노동부 | 고용센터 |

**두 트랙이 별개라는 것은 담당자조차 묻습니다.** 경상남도교육청 지침 Q&A의 실제 문항입니다.

> **Q. 특수교육대상자 선정 희망 학생 가운데 상당수는 이미 보건복지부에 장애인 등록이 되어 있습니다. 장애인으로 등록되어 있으면 …**

`[1차 자료]` 「2025 특수교육대상자 선정·배치 업무 처리 지침」 경상남도교육청, Q&A장

### 1.3 같은 교육청 **안에서도** 정보가 안 흐른다 🆕

강원도교육청 지침의 「선정·배치 유의사항」에 이 문장이 있습니다.

> ### ◼ 특수교육대상자 선정·배치 담당자는 배치 결과를 **반드시 치료업무, 방과후업무 담당자에게** 배치 결과를 **공유**하여 마음모아카드 **부정사용 예방**

**세 가지를 동시에 말해 줍니다.**

| 읽히는 것 | 의미 |
|---|---|
| 선정·배치 / 치료 / 방과후 담당이 **다른 사람이다** | 같은 교육지원청 안에서도 업무가 쪼개져 있음 |
| 지침에 **"반드시 공유하라"**고 써야 했다 | **지금 자동으로 흐르지 않는다는 뜻** |
| 이유가 **"부정사용 예방"**이다 | 정보 미공유가 실제 사고로 이어진 적이 있다 |

> **문제는 부처 사이에만 있는 게 아닙니다. 한 건물 안에서도 있습니다.**
> 그리고 이건 저희가 지어낸 장면이 아니라 **정부가 자기 지침에 적어 놓은 문장**입니다.

`[1차 자료]` 「특수교육대상자 선정·배치 업무 길잡이」 강원특별자치도교육청·강원특수교육지원센터

### 1.4 제도 이름이 **지역마다 다르고, 시간이 지나면 또 바뀐다** 🆕

#### ① 공간 축 — 같은 지원인데 시도마다 이름이 다르다

치료지원·방과후활동비를 지급하는 교육청 바우처 카드입니다. **제도의 실질은 같은데 이름이 전부 다릅니다.**

| 시도 | 카드 명칭 |
|---|---|
| 서울 | **굳센카드** |
| 경기 | **꿈이든카드** |
| 인천 | **참좋은카드** |
| 강원 | **마음모아카드** |
| 충남 | **디딤카드** |
| 경남 | **특기적성비지원카드** |

> **"우리 애 치료비 지원 카드"를 검색하면, 사는 곳에 따라 여섯 개의 다른 이름이 나옵니다.**
> 부모가 이사하면 이전 지역의 카드 이름은 아무 데도 쓸 수 없습니다.

**여기에 두 가지가 더 있습니다.**

- **강원의 「마음모아카드」는 공개 검색으로 잘 잡히지 않습니다.** 지침 문서에는 명칭이 나오지만, 웹에서는 "강원 특수교육 바우처" 정도로만 확인됩니다. **담당자가 검색으로 찾을 수 없는 제도가 실재한다는 뜻입니다.**
- **경남의 「특기적성비지원카드」는 이름부터 범위가 달라 보입니다.** 치료지원과 특기적성비를 분리 운영하는지 확인이 필요합니다 (10장 신규 과제).

#### ② 시간 축 — 용어가 폐지돼도 문서가 못 따라간다 ★

**2019년 7월 1일 장애등급제가 폐지되고 「장애등급」이 「장애정도」로 바뀌었습니다.**

그런데 **6년이 지난 2025년 지침에서 두 시도가 서로 다르게 쓰고 있습니다.**

| | 「장애등급」 표기 | 「장애정도」 표기 | 실제 문장 |
|---|---|---|---|
| **강원** | **1회** | 16회 | *"2019. 7. 1.자 이후 장애인등록인 경우 등급을 **'장애정도가 심한' 또는 '장애정도가 심하지 않은'으로 기재**"* — 전환을 안내함 |
| **경남** | **14회** | 22회 | *"학교장의견서, **장애등급 결정서**, 장애인증명서, 장애인복지카드 사본 중 택 1"* — 제출 서류로 반복 명시 |

> ## 💥 **결과가 무엇이냐면**
> 경남 지침만 보고 안내하는 담당자는 부모에게 **"장애등급 결정서를 가져오세요"**라고 말하게 됩니다.
> **그런데 2019년 7월 이후 등록한 부모에게는 그런 서류가 없습니다.**
>
> 부모는 주민센터에 갔다가 되돌아옵니다. 담당자 잘못이 아닙니다. **공식 지침이 그렇게 적혀 있습니다.**

`[입증]` [보건복지부 — 2019년 7월 장애등급제 폐지](https://www.mohw.go.kr/board.es?mid=a10503010100&bid=0027&act=view&list_no=347101) · [정책브리핑 — 장애등급제 폐지](https://www.korea.kr/special/policyCurationView.do?newsId=148866962) · 강원·경남 지침 원문 대조 (2026.08 직접 확인)

#### ③ 그래서 이게 왜 문제의 핵심인가

**제도가 없어서 못 받는 게 아니라, 제도를 부르는 말이 계속 바뀌어서 못 찾습니다.**

| 바뀌는 것 | 실례 |
|---|---|
| 지역이 바뀌면 **이름**이 바뀐다 | 디딤카드 ↔ 마음모아카드 ↔ 꿈이든카드 |
| 법이 바뀌면 **용어**가 바뀐다 | 장애등급 → 장애정도 (2019) |
| 기관 이름도 바뀐다 | 강원도교육청 → **강원특별자치도교육청** (2023) |
| 그런데 **문서는 그대로 남는다** | 온맘에 2022년 8월 게시물 잔존 (5.1) |

> **이것이 AI가 필요한 진짜 이유입니다.** 링크 모음은 사람이 관리할 수 있습니다. **매년 17개 시도의 명칭 변경과 용어 개정을 추적해 다시 구조화하는 것**은 못 합니다 (4.4).

### 1.5 얼마나 큰 문제인가

발달재활서비스 **평균 대기 기간이 긴 지역**에 서울·인천·경기와 함께 **강원**이 포함됩니다. 대기자가 많아서가 아니라 **제공기관이 적어서** 오래 기다립니다.

## 2. 신청 절차 — 1차 자료로 확정함

> **이전 판에서 "공개 자료로 복원했으며 확인 필요"라고 적었던 부분입니다. 두 시도 지침으로 확인을 마쳤습니다.**

### 2.1 두 트랙이 따로 흐른다

```
      [교육 트랙 — 교육청]                 [복지 트랙 — 복지부]

  ① 조기 발견 / 선별검사                ① 병원 진단 · 진단서
  ② 진단·평가 의뢰 (보호자 또는 학교장)   ② 장애 정도 심사 · 등록
  ③ 교육장이 지원센터에 회부 (즉시)       ③ 발달재활서비스 신청 (소득 심사)
  ④ 진단·평가 실시 ★30일 이내            ④ 바우처 발급 → 제공기관 (대기)
  ⑤ 특수교육운영위원회 심사               ⑤ 방과후활동 등 신청
  ⑥ 선정·배치 통보 ★2주 이내
  ⑦ 학교 등교 · 개별화교육계획
```

`[근거]` 장애인 등에 대한 특수교육법 제14~17조 · 장애아동복지지원법 제21조 · 강원/경남 지침

### 2.2 두 지역 대조 — **절차는 같고 이름만 다르다**

| 단계 | 강원 | 경남 |
|---|---|---|
| 의뢰 | 본인·보호자 또는 학교장 → 교육지원청 | 보호자 또는 학교장(보호자 동의) |
| 회부 | 교육장 → 지역특수교육지원센터 (즉시) | 교육감·교육장 → 특수교육지원센터 |
| 진단·평가 | 지역 진단·평가팀, **30일 이내** | 특수교육지원센터, **30일 이내** |
| 심사 | 시·군 특수교육운영위원회 | 시·군 운영위(영유초중) / 도 운영위(고) |
| 통보 | **결과보고 후 2주 이내** | **최종의견 통지 후 2주 이내** |
| 관할 | 영유아·초·중 = 교육지원청 / **고 = 도교육청** | **동일** |
| 진단·평가 의뢰서 | **[서식 3]** | **[서식 2]** |
| 기초조사 | **기초조사 카드** (보호자용/담임용 분리) | **기초조사서** (일반/건강장애) |

> ## 💡 **이것이 확장 가능성의 증거입니다.**
> 이전 판에서는 *"구조는 같고 데이터만 교체하면 된다"*고 **주장**했습니다. 이제 **두 지역 공식 문서를 대조해서 보여 줍니다.**
>
> *"강원과 경남 지침을 대조했습니다. 절차는 동일하고 서식 번호와 명칭만 다릅니다. 그래서 지역 확장은 개발이 아니라 데이터 교체입니다."*

### 2.3 마감일이 교육 트랙 안에만 **12개**

| # | 항목 | 기한 |
|---|---|---|
| 1 | 진단·평가 실시 | 회부일로부터 **30일 이내** |
| 2 | 선정·배치 결정 통보 | 결과보고 후 **2주 이내** |
| 3 | 심사청구 결정 통보 | **30일 이내** |
| 4 | 행정심판 제기 | 통보일로부터 **90일 이내** |
| 5 | 개별화교육계획(IEP) 송부 | 전출일로부터 **14일 이내** |
| 6 | **발달지체 재선정** | **만 9세 생일 도래 전** |
| 7 | **건강장애 재심사 신청** | **매 학년도 말까지 (매년)** |
| 8 | 학습장애·정서행동장애 재선정 | **중학교 진학 시** |
| 9 | 재취학 여부 확인 | **12월 말** |
| 10 | 유치원 배치(처음학교로) | **10월 말 선배치자 입력** |
| 11 | 취학유예 | **1년 이내**, 연장 시 운영위 심의 |
| 12 | 고교 계열 변경 전입학 | **2학년 1학기 성적산출 직전까지** |

**6~9번이 특히 중요합니다. 이미 받고 있던 지원이 끊기는 항목입니다.**

강원 지침의 예시입니다.

> *"9세가 되는 생년월일이 2026. 3. 14.일 경우 → **2026. 3월 말일까지 유지 후 종료**"*
> *"재심사 시 부결되더라도 9세까지 유지 후 특수교육지원(**방과후학교, 치료지원**) 종료"*

그리고 담당자 업무로 이렇게 적혀 있습니다.

> *"매년 발달지체 대상자로 선정된 학생을 **파악하여** 학교 및 보호자에게 재심사 안내"*

> **지금 담당자가 손으로 하고 있는 반복 업무이고, 생년월일만 있으면 기계적으로 계산되는 날짜입니다.**

### 2.4 문의가 발생하는 지점

| 막히는 지점 | 부모의 질문 | 지금 누가 답하나 |
|---|---|---|
| 교육 ① ↔ 복지 ① | *"진단을 어디서 먼저 받아야 하나요?"* | 정해진 곳이 없음 |
| 교육 ⑦ ↔ 복지 ⑤ | *"방과후는 학교 것과 복지 것 중 뭘 받나요?"* | **양쪽 다 소관 밖** |
| 이사 | *"전에 받던 걸 여기서도 받나요?"* | **지역마다 이름부터 다름** (1.4) |
| 재선정 | *"작년까지 받던 게 왜 끊겼나요?"* | **끊긴 뒤에 묻게 됨** |

### 2.5 도구가 끼어드는 자리

```
   학부모 문의 ─▶ 담당자 ─▶ [ 이 도구 ] ─┬─▶ ① 담당자용 확인 시트
                                          └─▶ ② 학부모용 안내문
```

**부모가 직접 쓰는 도구가 아닙니다.** 담당자가 상담 중에 쓰고, 결과물을 부모에게 건넵니다.

## 3. 사용자 · 수혜자 · 구매자

> 가상 인물이나 가상 사례를 넣지 않습니다. **제도상 확인 가능한 사실**과 **아직 확인하지 못한 것**만 적습니다.

### 3.1 사용자 — 기관 담당자

**제도상 사실**

- 특수교육지원센터는 **교육지원청 소속**이며 진단·평가, 배치 실무, 학부모 상담을 담당합니다
- **순환보직 대상**이므로 특수교육 전공자가 아닌 담당자가 배치될 수 있고, 담당이 바뀌면 지식이 사라집니다
- 소관은 **교육청 제도**에 한정되며 복지·의료·고용은 소관 밖입니다
- **같은 교육지원청 안에서도 치료·방과후 담당자가 따로 있습니다** (1.3)

**반복 문의가 존재한다는 근거** 🆕

두 시도 지침 모두 **Q&A 장을 따로 두고 있고, 겹치는 질문이 있습니다.** 지침에 Q&A를 실었다는 것은 **반복해서 물어온다는 뜻**입니다.

| 두 지역에 공통으로 실린 질문 |
|---|
| **"기초 상담 시 필요한 정보 및 안내사항에는 어떤 것들이 있을까요?"** |
| "특수학교가 없는 지역인데 타지역 특수학교로 배치받으려면?" |
| "이사·전학 절차가 어떻게 되나요?" (타시군 / 타시도) |
| "과연령자가 선정되길 희망하면?" |
| "취학을 유예하고 싶습니다" |
| "가정폭력 피해로 비밀전학 시 조치사항은?" |

> **첫 번째 질문이 이 서비스의 정의와 같습니다.** *"기초 상담 시 필요한 정보와 안내사항"* — 그 답을 한 화면으로 만드는 것이 이 도구입니다.

**아직 확인하지 못한 것** — 문의 빈도, 1건당 소요 시간, 소관 밖 문의 비중. 인터뷰가 필요합니다 (10장).

### 3.2 수혜자 — 학부모

아이에게 장애가 있다는 것을 알게 된 직후의 부모는 **무엇부터 해야 하는지 모르는 상태**입니다.

이 도구는 부모에게 직접 팔지 않습니다. **담당자를 거쳐 안내문 형태로 도달합니다.** 이유는 두 가지입니다. ① 정보에 접근할 줄 아는 부모에게만 도달하면 격차가 재생산됩니다 ② 취약계층에 과금하는 구조가 됩니다.

### 3.3 구매자 — 교육청 (B2G)

**사용자는 계약 당사자가 될 수 없습니다.** 특수교육지원센터는 별도 법인이 아니라 교육지원청 안에 설치된 조직이기 때문입니다.

> **장애인 등에 대한 특수교육법 제11조 제1항** — 교육감은 … **시·도교육청 및 모든 하급교육행정기관에 특수교육지원센터를 설치·운영**하여야 한다

시행령은 **독립된 공간 확보**와 **특수교육 분야 전문인력 배치**를 요구합니다. 즉 **"설치·운영"이지 "위탁"이 아닙니다.**

```
교육부 (중앙정부)
  │   ※ 지휘·감독 관계 아님 — 시도교육청은 지방교육자치 주체
  ▼
시도교육청 (17개) ── 교육감
  │   · 교육비특별회계 편성·집행 주체
  │   · 고등학교 선정·배치 결정 (도 특수교육운영위원회)
  ▼  「하급교육행정기관」
교육지원청 (약 176개) ── 교육장
  │   · 영유아·초·중 선정·배치 결정 (시·군 특수교육운영위원회)
  ├── 특수교육지원센터   ← 법인격 없음. 계약 주체가 될 수 없음
  └── 각급학교
```

**두 지침에서 확인되는 실제 모습** — 양쪽 다 2층 구조이고, 학교급에 따라 결재선이 갈립니다.

| | 강원 | 경남 |
|---|---|---|
| 도 단위 | 강원특수교육지원센터 (도교육청) | 도교육청 유아특수교육과 |
| 지역 단위 | 지역특수교육지원센터 (교육지원청) | 지역교육지원청 |
| 영유아·초·중 | 시·군 운영위 → **교육장** 결정 | 동일 |
| 고등학교 | 도 운영위 → **교육감** 결정 | 동일 |

**아직 확인하지 못한 것** — 교육장에게 위임된 계약 금액 한도(시도별 위임전결 규정이 다름), 예산 항목, 실제 조달 경로 (10장).

## 4. 솔루션

### 4.1 입력과 출력

**입력** — 거주지(시군) · 장애영역 · **생년월일** · 학교급 · 현재 이용 중인 지원

> **생년월일을 받는 이유는 나이 계산이 아니라 마감일 계산입니다.** 발달지체 재선정은 만 9세 생일 기준이라 생년월일 없이는 계산되지 않습니다 (2.3).

**출력 ① 담당자용 확인 시트** *(예시: 강원 · 자폐성장애 · 취학 예정)*

| 구분 | 내용 |
|---|---|
| **제출 서류** | 선정·배치 신청자 명단(엑셀) · 진단·평가 의뢰서 · 기초조사 카드(보호자용/담임교사용) · 배치 신청서 · 개인정보 동의서 · 학교장 의견서 또는 장애인증명서 중 택1 |
| **필수 검사** | 자폐성 검사(K-CARS-Ⅱ / K-ADS / ASDS / K-GARS-Ⅱ 중 1) · 적응행동검사(SMS / NISE-K·ABS / K-Vineland-Ⅱ / SIB-R 중 1) · 기초학습검사 *(취학 전 유아는 생략 가능)* |
| **기한** | 회부 후 **30일 이내** 진단·평가 → 결과보고 후 **2주 이내** 통보 |
| **참고** | 최근 **6개월 이내** 병원 검사 결과 활용 가능 · 병원 진단 우선 안내 |
| **⚠ 놓치기 쉬움** | 배치 희망교는 **3지망까지** 작성해야 함 — 미작성 시 운영위 임의 배치 |
| **⚠ 용어 주의** | 2019.7.1. 이후 등록자는 **「장애등급」이 아니라 「장애정도」** 표기 — 「장애등급 결정서」라는 서류는 없음 (1.4-②) |
| **⚠ 소관 밖** | 복지부 장애인 등록은 **교육청 선정과 별개 절차**임을 보호자에게 안내 |
| **지역 제도** | 강원 = **마음모아카드** (치료지원·방과후) — 타 시도는 명칭이 다름 |
| **근거** | 특수교육법 제15·16·17조 · 강원 선정·배치 업무 길잡이 |

**출력 ② 학부모용 안내문** — 위를 *"언제까지 · 어디에 · 무엇을"* 세 줄로 바꾼 한 장.

> **⚠ 표시된 세 줄이 이 도구의 정체입니다.** 3지망 미작성으로 임의 배치되는 것, 없는 서류를 요구받는 것, 복지 등록과 교육 선정이 별개인 것 — **전부 지침에는 있지만 부모는 모릅니다.**

### 4.2 하지 않는 것

> ## **판정하지 않습니다. 확인 목록을 줍니다.**

| ❌ 하지 않음 | ✅ 대신 |
|---|---|
| "이 아동은 방과후활동 대상입니다" | "방과후활동을 확인하세요. 요건은 이것, 근거는 여기입니다" |
| "이 조합은 중복이라 불가합니다" | "⚠ 중복 제한이 있을 수 있습니다. 사업안내 ○조를 확인하세요" |
| 서류를 대신 작성·제출 | 준비 서류 목록과 서식 위치를 안내 |

**이유** ① 입력 몇 가지로 자격을 확정할 수 없습니다(소득·재산·장애 정도·기존 수급 이력 필요) ② 잘못된 확정 안내는 실제 피해가 됩니다 ③ 서류 작성·제출 대행은 **행정사법**이 정한 영역입니다.

### 4.3 개인정보를 다루지 않습니다 🆕

| 원칙 | 내용 |
|---|---|
| **저장하지 않는다** | 입력값은 결과 생성에만 쓰고 **보관하지 않습니다.** 아동 명단이나 이력을 담는 DB를 두지 않습니다 |
| **식별정보를 받지 않는다** | 이름·주민번호·연락처·진단서 원문을 입력받지 않습니다. 생년월일은 **마감일 계산용**이며 저장되지 않습니다 |
| **명단 관리 기능을 넣지 않는다** | *"발달지체 아동 전원의 재선정일을 관리"*하려면 명단을 보유해야 합니다. **1단계에서는 하지 않습니다** |
| **데모는 가상 데이터로** | 시연에 쓰는 모든 아동 정보는 **가상으로 구성**합니다 |

> **이 원칙은 제약이 아니라 판매 논리입니다.** 교육청 도입 시 가장 먼저 걸리는 것이 개인정보 처리 요건인데, **처리할 개인정보가 없으면 그 관문이 사라집니다.**
>
> 그리고 4.4의 "업무가 늘지 않는 설계"와 같은 방향입니다 — **입력 즉시 출력, 보관 없음.**

### 4.4 담당자의 업무가 늘지 않는 설계

새 도구는 대개 새 입력 업무를 만듭니다. 그래서 이렇게 막았습니다.

- **입력은 상담 첫머리에 어차피 묻는 것만** (거주지·장애영역·생년월일·학교급)
- **결과물이 그 자리에서 나온다** — 나중에 다시 들어올 일이 없음
- **진행 상태 관리를 넣지 않는다** — 매일 갱신해야 살아 있는 기능은 유지되지 않음
- **기록은 부산물** — 생성한 안내문이 곧 안내 기록

> **판매 논리는 "시간 절약"이 아니라 "누락 방지와 기록"입니다.** 시간 절약은 증명해야 하지만, 무엇을 안내했는지 근거와 함께 남는다는 것은 **도입 즉시 참**입니다.

### 4.5 AI를 쓰는 지점

| 단계 | AI 역할 | 왜 AI인가 |
|---|---|---|
| **제도 데이터 구조화** | 지침·조례·사업안내에서 대상·요건·서류·검사·기한 추출 | **문서 형식이 지역마다 다르고**(hwp/pdf, 서식 번호 상이) 규칙 파싱이 불가능 |
| **명칭·용어 대조** 🆕 | 지역별 카드 명칭과 개정 용어를 같은 개념으로 묶기 | **디딤카드=마음모아카드=꿈이든카드**를 사람이 17개 시도 × 매년 대조할 수 없음 |
| **안내문 생성** | 확인 시트를 학부모용 문장으로 변환 | 담당자별 안내 품질 편차 해소 |
| ❌ 자격 판정 | **쓰지 않음** | 4.2 |

**AI를 빼면 남는 것** — 지역별 제도 구조화 DB, **명칭 대응표**, 마감일 규칙 테이블. **자산이 남습니다.**

**사람이 손으로 못 하는 이유** — 1회 정리는 됩니다. **17개 시도의 명칭 변경과 법령 용어 개정을 매년 반영해 다시 구조화하는 것**은 못 합니다. **경남 지침에 2019년 폐지 용어가 2025년까지 남아 있는 것**이 그 증거입니다 (1.4-②).

### 4.6 설계 원칙

1. **판정하지 않는다** — 확인 목록과 근거만. 최종 판단은 담당자
2. **개인정보를 저장하지 않는다** — 4.3
3. **근거를 반드시 붙인다** — 모든 항목에 법령·지침·조례 링크
4. **최신성을 표시한다** — 제도마다 "○○년 ○월 기준 / 확인일"을 병기
5. **옛 이름도 함께 보여준다** 🆕 — *"장애등급 결정서(현재 명칭: 장애정도 결정 통지서)"* 처럼 **바뀌기 전 이름을 병기**해야 담당자가 지침과 대조할 수 있습니다

## 5. 경쟁과 차별점

### 5.1 기존 서비스

| 서비스 | 성격 | 한계 |
|---|---|---|
| **복지부 AI 정책실험실** | 복지공무원 업무지원 AI (경기 5개 시 실증, 전국 확산 예정) | **복지부 소관 = 교육청 제도 없음** |
| **개인별지원계획(IPSP)** | 발달장애인지원센터 법정 사업. 담당자가 서비스 조합을 계획서로 작성 | 복지부 소관, 대기 발생, **교육청 제도 미포함** |
| **보조금24** | 중앙+지자체 혜택 6,774개 맞춤 안내 | 교육청 제도 없음, **마감일·중복 제한 없음** |
| **온맘** (국립특수교육원) | 생애주기별 제도 **게시판** | 거주지 입력·확인 기능 없음, **2022년 게시물 잔존** (2026.08 직접 확인) |

**전부 부모용 조회 서비스이거나 복지부 소관입니다. 담당자가 상담 중에 쓰는 도구는 없습니다.**

### 5.2 진입 기회와 진입장벽을 나눈다

> **"부처가 달라서 정부도 못 한다"는 진입 기회이지 진입장벽이 아닙니다.** 자리가 비어 있다는 뜻이지, 뒤따라오는 사람을 막는 벽은 아닙니다.

| | 무엇인가 |
|---|---|
| **왜 지금 들어가나** (기회) | 교육·복지 경계가 비어 있다. 복지부 사업은 교육청 제도를 다루지 않는다 |
| **왜 못 따라오나** (장벽) | ① 검증된 교육×복지 통합 데이터 ② **명칭·용어 변경을 추적하는 갱신 체계** ③ 제도 간 관계 정보 ④ 축적된 안내 이력 |

**②가 핵심이고, 이번에 실체가 확인됐습니다.** 카드 이름이 6개 시도에서 6개이고, 법령 용어가 6년 지나도 문서에 반영되지 않습니다. **이 대조표를 유지하는 일 자체가 진입장벽이며, 갱신을 구독료의 근거로 전환합니다.**

### 5.3 남는 빈틈

1. **교육과 복지를 한 화면에서 본다** — 부처가 달라 아무도 못 함
2. **담당자가 상담 중에 쓰는 도구다** — 전부 부모용 조회 서비스
3. **마감일과 재선정 시기를 말한다** — 근거 12줄 확보 (2.3)
4. 🆕 **지역마다 다른 이름을 같은 제도로 묶어 준다** — 아무도 안 함

*(지역 반영 자체는 차별점이 아닙니다 — 보조금24가 지자체 혜택 6,774개를 커버합니다. **다만 교육청 제도의 명칭 대조는 하지 않습니다.**)*

## 6. 사업 모델 — B2G2C

### 6.1 왜 B2G가 유리한가 — **직할 구조**

교육청 조직에는 **중간에 계약 관계가 하나도 없습니다.** 교육감 → 교육장 → 특수교육지원센터가 전부 같은 법인격 안의 행정 위계입니다 (3.3).

| | **교육 라인** (1순위) | 복지 라인 |
|---|---|---|
| 관계 | **직할** — 설치·운영 | **민간 위탁** — 법인이 수탁 |
| 도입 | **한 번 결정되면 산하 전체가 사용자** | **기관마다 따로 설득** |
| 영업 비용 | 낮음 | 높음 |

> ## 💡 **1개 시도교육청을 도입시키면 그 산하 교육지원청 전부가 사용자가 됩니다.**
> **강원이면 17개, 경기면 25개입니다.** 학생 팀이 기관 열 곳을 돌며 파는 그림보다 훨씬 현실적이고, *"학생 팀이 영업이 되겠느냐"*는 질문에 대한 구조적 답이 됩니다.

### 6.2 판매 경로

| 순위 | 대상 | 계약 주체 | 근거 |
|---|---|---|---|
| **1** | **시도교육청 구축 용역** | **교육감** | 교육비특별회계 편성 주체. 시스템 용역 조달 경로 존재. 1개 시도 검증 후 횡전개 |
| 2 | 연간 유지보수 (구축비의 10~15%) | 교육감 | **명칭·용어·기한이 매년 바뀌므로** 갱신 수요가 구조적으로 발생 (1.4) |
| 3 | 교육지원청 단위 소액 도입 | 교육장 | 위임전결 한도 내. **한도 확인 필요** |
| 4 | 장애인가족지원센터·복지관 | 수탁 법인 | 민간 위탁이라 자체 예산 가능성. **여기만 B2B(비영리)** |
| — | 발달장애인지원센터 | — | 복지부 소관 — IPSP·복지부 AI와 정면 경합. 후순위 |

> **개별 센터 단위 구독은 성립하지 않습니다.** 특수교육지원센터는 법인격이 없어 **계약 당사자가 될 수 없습니다** (3.3).

### 6.3 쓰는 곳과 사는 곳이 갈린다 — 메시지가 둘 필요하다

MVP를 **초등 취학**으로 잡으면, 실사용은 교육지원청에서 일어나는데 구축 용역 규모의 계약은 도교육청에서 납니다.

| 상대 | 할 말 |
|---|---|
| **도교육청** (사는 곳) | *"산하 17개 교육지원청의 안내 품질이 균일해집니다. 담당자가 바뀌어도 유지됩니다."* |
| **교육지원청** (쓰는 곳) | *"전화 한 통이 3분에 끝나고, 무엇을 안내했는지 근거와 함께 남습니다."* |

### 6.4 구매 이유 네 가지

| | |
|---|---|
| **누락 방지** | 소관 밖 제도와 **재선정 마감**이 빠지는 것을 막습니다 |
| **기록** | 무엇을 안내했는지 근거와 함께 남습니다 |
| **품질 균일화** | 담당자가 바뀌어도 안내가 유지됩니다 — 순환보직에 대한 직접 대응 |
| **도입 장벽이 낮다** | **개인정보를 저장하지 않으므로** 처리 요건 심사가 가볍습니다 (4.3) |

**⚠ 위임전결 한도·예산 항목·조달 경로(나라장터/수의계약/계약심사)는 아직 확인하지 못했습니다** (10장 최우선).

## 7. MVP

| 항목 | 범위 |
|---|---|
| 지역 · 대상 | **강원 1개 시** · 발달장애(지적+자폐성) |
| 전환 시점 | **초등 취학** + **발달지체 만 9세 재선정** |
| 제도 수 | **10~15개, 수작업으로 정확하게** |
| 화면 | 조건 입력 → 확인 시트 → 학부모용 안내문 |
| 데이터 | **전부 가상.** 실제 아동 정보를 쓰지 않습니다 |
| 만들지 않는 것 | 실시간 크롤링, 공적 데이터 연계, 자격 최종 판정, **아동 명단·진행 상태 관리** |

### 7.1 데모 장면 두 개

**① 한 번 입력하면 두 장이 나온다**
왼쪽 담당자용 확인 시트, 오른쪽 학부모용 안내문. **부처가 섞인 목록이 한 화면에 있다는 것 자체**가 차별점의 증거입니다.

**② 같은 조건에 지역만 바꾼다** 🆕
강원으로 입력하면 **마음모아카드**, 경남으로 입력하면 **특기적성비지원카드**, 충남이면 **디딤카드**가 나옵니다.
그리고 확인 시트에 이 줄이 뜹니다 — *"⚠ 2019.7.1. 이후 등록자에게 「장애등급 결정서」는 존재하지 않습니다. 「장애정도」로 안내하세요."*

> **②는 기존 서비스 어디에서도 나올 수 없는 화면입니다.** 지역별 명칭 대응과 폐지 용어 경고를 동시에 하는 곳이 없습니다.

## 12. 확장

| 축 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| **지역** | 강원 1개 시 | 강원 18개 시군 | **17개 시도** — 절차 동일 확인됨 (2.2) |
| **전환 시점** | 취학 + 발달지체 재선정 | +건강장애 매년 재심사, 초→중 재선정 | 고교 졸업 후 성인기 |
| **대상** | 발달장애 | 11개 장애영역 전체 | 장애아동 전체 |
| **기능** | 확인 시트 + 안내문 | +명칭 대응표 확대 | +중복 제한 경고 |
| **채널** | 특수교육지원센터 | 일반학교 특수교사 (74.1%) | 복지관·가족지원센터 |

**엔진의 실체**는 `조건 입력 → 지역 제도 DB 매칭 → 근거 붙은 확인 목록`입니다. **확장은 도메인이 아니라 "부처가 갈린 도메인"을 따라갑니다** — 노인 돌봄(복지부+지자체+건보), 장애 성인(복지부+고용부)에서 같은 구조가 성립합니다.

**왜 특수교육부터인가** — 부처가 가장 많이 갈려 있고(교육·복지·의료·고용), **날짜가 있는 마감이 12개** 존재해 효과 측정이 쉽습니다.
