# 해커톤 현황 — 된 것 · 안 된 것 · 찾을 것 · 계획

**2026-10-17 정리.** 해커톤은 2026-11-28이고, **모든 준비는 10월 안에 끝내는 것이 목표**다. 11월은 리허설과 평가 기준 맞춤에만 쓴다.

---

## 1. 방향 — 확정

| 항목 | 내용 |
|---|---|
| **관점** | **담당자가 이미 한계다 → 사람은 못 늘린다 → 담당자 손을 덜어 주는 도구가 꼭 필요하다.** 「소관이 갈라져 있다」는 부담의 *원인* ([발표 구성](해커톤-발표-구성.md)) |
| **원칙** | 규칙이 고르고 AI는 보조 · 판정하지 않는다 · 아동 정보 저장 안 함 · 모든 값에 출처 |
| **범위** | **강원·경남은 깊게 구현**, 16개 시도는 [출처 지도](제도-출처-지도.md)로 확장성 근거만. 전국 구현은 하지 않는다 |
| **데모 축** | 담당자의 하루 — 전화 상담 → 안내문(체크리스트) → 서류 접수 확인 → 공식 데이터 |
| **근거** | 정부기관 원문 통계만, 수치마다 대상을 밝힌다 ([발표 근거](해커톤-발표-근거.md)) |

## 2. 구현 상태

### ✅ 된 것

| 영역 | 내용 |
|---|---|
| 핵심 흐름 | 조건 입력 → 확인 시트 · 학부모 안내문 · 안내 전 확인사항 · 읽어 주기 · AI 안내문 |
| 입력 | 생년월일 숫자 입력(기본값 없음) · 거주 시·군 |
| 공식 API 3개 | 중앙부처복지서비스 · 지자체복지서비스 · 공공서비스(혜택) → `/api/welfare` |
| 공식 데이터 반영 | 복지 제도 4개 원문 대조(빠진 서류 2개 추가) · 교육청 제도 3개 강원·경남 공식 금액·서류·시기 · 경남 카드 이름 수정 ([대조 기록](공식데이터-대조.md)) |
| 화면 | 제도 카드 「공식 정보」 · 지역 자체사업 후보 · 안내문 □ 체크리스트 · 서류 누락 확인 + 보완 안내 |
| 화면 흐름 (10/17) | 첫 화면에 입력 칸 · 결과 순서(확인사항 → 안내문 → 접수 확인 → 자세히) · 「새 상담」 · 가상 게시판 제거 |
| 산출물 | [학부모 핵심 정보 스프레드시트](학부모-핵심정보.xlsx) · 근거 · 출처 지도 · [갱신 파이프라인](데이터-갱신-파이프라인.md) · 발표 구성 |
| 멘토 과제 | 기술 멘토 3개 완료 (핵심 기능 재정의 · API 실데이터 · 스프레드시트) |

### ⏳ 안 된 것 · 반쯤 된 것

| 항목 | 상태 | 왜 중요한가 |
|---|---|---|
| Supabase 갱신 파이프라인 | 설계만 | 「업데이트·유지보수」 약점의 답. **프로젝트 생성 필요(직접)** |
| 데모 안정성 | 대비 없음 | 발표장에서 API가 느리거나 막히면 공식 정보 칸이 빈다 — 마지막 값 보관이 필요 (Supabase가 겸한다) |
| 교육청 제도 「공식 정보」 칸 | 복지 쪽만 | 치료지원 등에도 행안부 원문을 붙일 수 있다 |
| 지역 자체사업 → 규칙 반영 | 후보 목록만 | 확인한 사업을 안내문까지 |
| 경남 2026 선정·배치 지침 | 미확인 | 서식 번호가 2025판 기준 |
| 광주·전남 통합 | 미반영 | 대조 표에만 영향 |
| 해커톤 발표 대본 · 슬라이드 | 구성만 | 블록 12개 흐름은 있고 원고·화면은 없다 |
