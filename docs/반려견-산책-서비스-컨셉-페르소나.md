# 서비스 컨셉 정의서 v1 — 반려견 산책 루트 서비스 (가칭: 멍로드)

작성일: 2026-08-11 (새 주제 — AI 트래커와 별개 프로젝트)

---

## 1. 정체성

> **"오늘 산책, 몇 분 하실래요?" — 원하는 산책 시간을 입력하면, 매번 다른 동선에 애견용품샵·애견동반 식당·간식 파는 마트를 엮어주는 반려견 산책 루트 생성 앱.**

- 카테고리: **산책 루트 생성기 + 로컬 커머스 연결** (만보기 아님, 단순 지도 앱 아님, 커뮤니티 아님)
- 한 줄 가치: 같은 동네에서도 산책이 매일 새로워진다 — 그리고 그 동선 위에서의 소비가 유기견 후원으로 이어진다

### 코어 루프 (이것이 서비스의 전부)

```
입력 (견종 + 오늘 원하는 산책 시간)
  → 루트 생성 (매번 다른 동선 + 경유지: 애견용품샵 / 애견동반 식당 / 간식 마트)
    → 소비·주문 (앱 통해 구매·주문 시 제휴 수수료 발생)
      → 기부 (수익 일부를 유기견 보호센터에 자동 기부)
```

### 동물복지 요소 (가볍게, 이 한 가지만)

- 견종 입력 시 **"이 견종은 하루 이 정도의 산책량이 필요해요"** 권장 산책량을 안내 (예: 보더콜리 90분+, 푸들 40~60분, 시츄 30분)
- 오늘 입력한 산책 시간과 권장량의 차이를 보여주는 정도까지만. 캠페인·교육 콘텐츠·경고 알림 등으로 확장하지 않는다 (결정 로그 참고)

## 2. 페르소나

### 주 페르소나 — 박지우 (29, 1인 가구 직장인)

| 항목 | 내용 |
|---|---|
| 반려견 | 웰시코기 "감자" (3살, 활동량 많은 중형견) |
| 생활 패턴 | 평일 퇴근 후 저녁 1회 + 주말 2회 산책. 시간은 있는데 **코스가 늘 같아서 본인이 먼저 지루함** |
| 페인포인트 | ① 동네 산책로가 3개뿐, 감자도 냄새 맡을 새 길이 없음 ② 애견동반 식당을 검색해도 정보가 오래돼 헛걸음 ③ 간식·용품은 온라인 최저가로 사지만 배송 기다리기 귀찮을 때가 많음 |
| 결정적 장면 | 주말에 "오늘은 좀 멀리 가볼까" 하고 검색 3개 앱(지도, 블로그, 인스타)을 오가다 30분을 씀 — **이 30분을 버튼 하나로 줄여주는 것**이 우리 서비스 |
| 지불 의사 | 구독료 자체보다 "제휴 할인 + 기부 리포트"가 묶이면 월 4,900원 수준은 낸다 |

### 부 페르소나 — 한명순 (58, 은퇴 후 소형견 2마리)

| 항목 | 내용 |
|---|---|
| 반려견 | 말티즈 2마리 (노령견 포함) |
| 생활 패턴 | 오전·오후 짧은 산책 2회. 무릎이 약한 노령견이라 **짧고 평탄한 코스**가 필요 |
| 페인포인트 | 산책량이 적절한지 늘 불안함 → **견종·나이별 권장 산책량 안내**가 이 페르소나의 진입 포인트 |
| 역할 | 시간 설정의 하한(15~20분 루트)과 경사도·계단 회피 옵션의 근거가 되는 페르소나 |

## 3. 핵심 기능 (MVP 범위)

| 기능 | 내용 | 우선순위 |
|---|---|---|
| 산책 시간 기반 루트 생성 | 시간(분) 입력 → 왕복 루트 자동 생성, 매번 다른 동선 보장 | ★ 코어 |
| 경유지 편성 | 루트 위 애견용품샵·애견동반 식당·간식 마트를 경유지로 배치 (켜고 끌 수 있음) | ★ 코어 |
| 견종별 권장 산책량 안내 | 견종 입력 시 하루 권장 산책량 1줄 표시 + 오늘 시간과의 차이 | ★ (가볍게) |
| 앱 내 주문·구매 | 경유지 매장의 간식·용품 주문, 픽업 | 수익 코어 |
| 기부 리포트 | "이번 달 내 소비로 ○○보호센터에 ○○원 기부됨" 월간 리포트 | 리텐션 장치 |

## 4. 수익 구조

```
[사용자] ── 구독료 ──→ [서비스] ←── 제휴 수수료·인센티브 ── [제휴 매장]
                          │
                          └── 수익 일부 ──→ [유기견 보호센터 기부]
```

| 축 | 내용 |
|---|---|
| 구독 | 월 구독: 무제한 루트 생성 + 제휴 매장 할인 + 기부 리포트. 무료 티어는 루트 생성 횟수 제한 |
| 인센티브 (제휴 수수료) | 앱 경유 주문·구매 건당 매장이 수수료 지불. 매장 입장의 유인: "개 데리고 오는 손님"을 확정적으로 데려다주는 채널 |
| 기부 연계 | 구독료·수수료의 일정 비율을 유기견 보호센터에 기부. 사용자에게는 월간 기부 리포트로 가시화 — 구독 해지를 막는 심리적 장치이자 브랜드 정체성 |

---

## 5. 콜드스타트 전략

- 애견동반 매장 데이터가 서비스의 생명 — 전국 커버 불가능. **애견 인프라 밀집 동네 1곳**(예: 서울숲·연남동급 상권)에서 시작
- 초기 매장 데이터는 수동 확보(직접 제휴 영업 + 검증), 이후 사용자 제보·매장 셀프 등록으로 확장
- 루트 생성 자체는 지도 API로 가능하므로, 병목은 기술이 아니라 **경유지 데이터 품질**임을 인지하고 시작
