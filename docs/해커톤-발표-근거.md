# 해커톤 발표 근거 — 1차 공식 통계

**2026-11-28 전국 해커톤용.** 사업 멘토링에서 짚은 축(예산 절감 · 인력 · 현장 문제 · 정책효능감)에
맞춰 정부기관 원문 통계만 모았다. 수집일 2026-10-11~12.

> **규칙 — 이 문서의 수치는 정부기관·공공기관 원문에서 직접 확인한 값만 싣는다.**
> 언론 기사, 기사에 실린 재인용 수치, 의원실 자료를 언론이 옮긴 것은 넣지 않는다.
> 「계산」은 확인한 원문 값으로 셈만 한 것이다. 발표에서 말할 때도 「계산」이라고 밝힌다.

## 발표 흐름

**수요는 늘었다 → 돈과 사람은 제자리다 → 이미 있는 사람의 반송·재문의를 줄인다 → 그게 정책효능감이다**

| # | 블록 | 한 문장 |
|---|---|---|
| ① | 시작 | **"학생은 12.6% 줄었는데, 특수교육대상자는 33.6% 늘었습니다."** |
| ② | 예산·인력 | 예산 비중은 10년째 4%대, 1인당 특수교육비는 오히려 줄었다 |
| ③ | 현장 문제 | 정보는 행정이 아니라 지인을 통해 온다. 발달지체·자폐는 10년간 3배 |
| ④ | 데모 | 규칙이 고르고, AI는 빈칸만 |
| ⑤ | 기대효과 | 정부도 신청주의를 줄이는 중 — 「마땅히 받아야 할 것」을 놓치지 않게 |
| ⑥ | 확장 | 고용 — 졸업 뒤 사회로 나가는 단계의 공백 |
| ⑦ | 닫기 | 판정하지 않는다. 마땅히 받아야 할 것을 놓치지 않게 확인 목록을 드린다 |

### 아 다르고 어 다르다 — 같은 기능을 구매자 언어로

| ❌ 이렇게 말하지 않는다 | ✅ 이렇게 말한다 |
|---|---|
| 인력이 부족합니다 | **사람을 늘릴 수 없는 자리에서, 이미 있는 사람의 반송·재문의를 줄입니다** |
| 학부모가 정보를 모릅니다 | **정보가 행정이 아니라 지인을 통해 옵니다.** 그래서 담당자가 건네는 종이 한 장이 필요합니다 |
| 혜택을 더 받게 해 줍니다 | **수혜가 아니라 마땅히 받아야 할 것을 놓치지 않게 합니다** — 정부 방향(신청 없이 지급)과 같습니다 |
| 업무 시간을 줄여 줍니다 | **확인 시간이 줄면 그만큼이 예산입니다** — 시범 운영에서 반송 건수·확인 시간을 KPI로 잽니다 |

> 2012년 50% → 2026년 22% 추이는 **2013년 기준 변경**(보호작업장 참여자 제외)이 섞여 있다.
> 특별전형 입학 1,191명과 대학 진학 1,836명은 다른 집단이라 더하거나 빼지 않는다.
