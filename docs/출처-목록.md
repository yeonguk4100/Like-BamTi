# 출처 목록 — 발표 근거 원문 링크

[발표 근거](해커톤-발표-근거.md)에 쓴 원문을 **왜 찾았는지**로 묶었다. 링크 점검 2026-10-19. 41개를 모두 열어 확인했고, 깨진 3개는 같은 게시물의 다른 주소로 바꿨다.
출처 링크를 확보하지 못한 행(발달재활 10만 명 목표 · 대졸자 취업률 · 강원·경남 임용 경쟁률)은 10/19 지웠다.
