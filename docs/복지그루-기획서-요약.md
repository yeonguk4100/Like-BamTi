## 1. 문제 — 세 겹으로 갈라져 있다

| 무엇이 갈라져 있나 | 근거 |
|---|---|
| **부처가 갈려 있다** — 교육 · 복지 · 의료 | 소관별 신청처 상이 |
| **같은 교육청 안에서도 담당자가 갈려 있다** | 강원 지침 원문 — *"배치 결과를 **반드시** 치료업무, 방과후업무 담당자에게 공유"* |
| **제도 이름이 지역마다 다르고, 폐지된 용어가 지침에 남아 있다** | 카드 명칭 6개 시도 6종 · 경남 2025년 지침에 「장애등급」 14회 |

### ★ 이 문제의 가장 구체적인 형태 둘

#### ① 만 9세에 두 부처의 지원이 같이 끝난다 *(문서에서 찾음)*

| 소관 | 무엇이 끝나나 |
|---|---|
| **교육청** | 발달지체 특수교육대상자 지위가 **만 9세가 되는 달 말일**에 종료 |
| **복지부** | **장애 등록 없이** 발달재활서비스를 받고 있으면 **만 9세가 되는 달**까지만 지원 |

발달지체는 특수교육법상 영역이지만 **장애인복지법의 등록 유형이 아닙니다.** 그래서 등록장애 없이 「만 9세 미만 특례」로 발달재활을 받게 되고, 그 특례가 끝나는 시점이 교육청 쪽 종료 시점과 같습니다.

> **소관이 달라 어느 쪽도 다른 쪽을 알려주지 않습니다.** 부모는 같은 달에 두 가지를 동시에 잃고, 그때야 묻습니다.
> 담당자도 모릅니다 — 복지부 쪽은 소관 밖이니까요.

#### ② 어린이집 아동에게는 교육청 공문이 가지 않는다 *(담당자가 말함)*

> *"**초등학교·중학교는 공문을 보내기에 놓치는 부분이 거의 없음.** 반면 **어린이집에 다니는 아이들이 자주 놓침.**
> 교육청 소속이 아니기 때문에 공문을 보내지 못하고 행정복지센터를 통해서 거쳐야 하는 거라 **많이 누락이 되긴 함**"*

**취학 직전이 가장 중요한 시기인데 그 시기 아동 상당수가 어린이집에 있습니다.** 놓치면 특수학급 정원(TO)에 달려 있고, 정원이 없으면 대응이 지역마다 달라 담당자도 확답하지 못합니다.

### 규모

- 특수교육대상자 **120,735명** (2025). 10년간 **+37%**. 그중 **74.1%가 일반학교** — 그 특수교사에게도 복지는 소관 밖
- 복지 사각지대 원인 1위 **"신청하지 않아서" 45.7%**, 그 이유 1위 **"몰라서" 70.9%** (한국보건사회연구원, 담당자 700명)

## 2. 담당자에게 물었더니 — 여기서 방향이 바뀌었다

전화로 다섯 가지를 물었습니다 ([전문](담당자-인터뷰.md)).

| # | 답 |
|---|---|
| Q1 | **서류는 거의 빠뜨리지 않음** (사전 안내를 하기 때문). 대신 **기초조사서 기술이 부실해 재요청**하고 담임교사에게 다시 확인 |
| Q2 | **운영위원회 월 1회.** 회의 직후 신청하면 한 달, 직전이면 바로 결과 |
| Q3 | *"대부분 특수교육대상자가 되면 **교육청에서 어떤 혜택을 주는지**를 가장 궁금해함"* |
| Q4 | **어린이집 아동이 누락됨** — 공문을 못 보내기 때문 |
| Q5 | 놓치면 **정원(TO)에 달림.** 없으면 지역마다 대응이 달라 확답 못 함 |

> **⚠ 인용을 합치지 않습니다.** 20곳 정도에 문의해 답이 비슷했지만, 위 인용은 **그 통화에서 나온 말**입니다.
> *"사전에 안내를 드리기 때문에 빠뜨리는 건 거의 없음"*(Q1)은 **그 센터가 사전 안내를 잘 하고 있다는 뜻**이고,
> 모든 센터가 같다고 볼 근거는 없습니다. 문의처가 교육청·지원센터·특수학교로 섞여 있어 유형별 집계가 필요합니다.

**목표는 그대로 「담당자의 일처리 시간 단축」입니다.** 인터뷰는 그 시간이 **어디에서 반복되는지**를 보여줬습니다.

| 반복되는 일 | 근거 |
|---|---|
| 사전 안내를 **매번 말로** 한다 | Q1 |
| **재요청**하고 **담임교사에게 다시 확인**한다 | Q1 |
| 대기 중 **진행 문의**를 받는다 | Q2 |
| **혜택 문의**를 받는다 | Q3 |

> **같은 사람에게 여러 번 연락이 갑니다.** 서류가 빠져서가 아니라 내용이 부족해서, 그리고 기다리는 동안 궁금해서입니다.
> 경로가 다를 뿐 **반복 노동은 그대로**입니다. 도구는 그 반복을 **한 장으로 앞당깁니다.**

그리고 담당자가 **아예 할 수 없는 것**을 채웁니다 — 어린이집 공문, 만 9세 복지부 종료, 소관 밖 절차·시기.
담당자가 소관 밖 제도를 **설명하게 만들면 업무 확대**입니다. 담당자는 조건만 넣고 종이를 건네고, **설명은 종이가 합니다.**

## 3. 무엇을 하는 도구인가

**판정하지 않습니다. 확인 목록을 줍니다. 개인정보를 저장하지 않습니다.**

```
담당자가 조건 입력 ─▶ ① 학부모용 안내문   ← 제품. 그대로 건넨다
 (거주지·장애영역·생년월일  ├▶ ② 안내 전 확인사항 (몇 줄)
  ·학교급·신청 상황)        └▶ ③ 자세히 보기 (접힘) ← 학부모가 파고들 때만
```

**안내문은 소관별이 아니라 순서대로 씁니다.** 이게 반송을 막는 부분입니다.

```
■ 1단계 — 먼저 다른 곳에서 갖춰 오실 것
· 학교장 의견서 또는 장애인증명서·복지카드 중 택 1
   → 재학(예정) 학교에서 「학교장 의견서」, 또는 읍면동에서 「장애인증명서·복지카드」
■ 2단계 — 지역 교육지원청에서 작성하실 것
· 진단·평가 의뢰서 [서식 3]   ← 서식 번호가 지역마다 다릅니다
```

지침에는 「학교장 의견서 **또는** 장애인증명서」가 **한 줄로** 적혀 있어 학부모가 어느 기관인지 판단하게 되어 있습니다. 도구는 이걸 갈라서 적습니다.

## 4. 규칙이 고르고, AI는 못 하는 것만 한다

| | 하는 일 |
|---|---|
| **규칙** (순수 함수) | 제도 선택 · 마감일 계산 · 서류 목록과 지역별 서식 번호 · 경고 생성 |
| **AI** ① | 규칙이 만든 결과를 **학부모가 읽을 문장으로** 옮긴다 (검색 끔) |
| **AI** ② | 우리 데이터에 **없는 칸을 웹에서 찾는다.** 출처 URL이 없으면 답을 내지 않는다 |
| **담당자** | 조건 입력 · **최종 판단** |

**데이터 구조화는 AI가 아니라 사람이 했습니다.** 지침 원문을 대조해 손으로 넣었고, 그 검증된 데이터가 자산입니다.

> 실제로 저희도 두 번 틀렸습니다 — 「청소년 방과후활동서비스」를 이름 그대로 중·고등학생용으로 잡았는데
> **만 6세부터**였고, 중복 제한 목록도 추측이었습니다. **담당자는 이 오류를 잡을 수 없습니다** — 모르는 영역이니까요.
> **틀린 데이터는 없는 데이터보다 나쁩니다.** 그래서 AI에게 제도를 고르게 하지 않습니다.

**안 만드는 것** — 자격 판정(잘못된 확정 안내는 실제 피해) · 서류 대행(⚖️ **행정사법**) · 아동 명단 저장(개인정보 처리 요건이 곧 도입 장벽) · 로그인

## 5. 사업 구조 — B2G2C

| | 누구 |
|---|---|
| **구매자** | 시도교육청 / 교육지원청 — **지방계약법을 타는 조달** |
| **사용자** | 기관 담당자 (특수교육지원센터) |
| **수혜자** | 학부모 — 무료. 안내문으로 도달 |

특수교육지원센터는 **법인격이 없어 계약 주체가 될 수 없습니다**(특수교육법 제11조). 교육청은 위탁이 아니라 **직할**입니다.

> **1개 시도교육청이 도입하면 산하 교육지원청 전부가 사용자가 됩니다. 강원이면 17개**
> (18개 시군 중 속초·양양 통합 운영). *"학생 팀이 영업이 되겠느냐"*에 대한 구조적 답입니다.

| 상대 | 할 말 |
|---|---|
| **도교육청** (사는 곳) | *"산하 교육지원청의 안내 품질이 균일해집니다. 담당자가 바뀌어도 유지됩니다."* |
| **교육지원청** (쓰는 곳) | *"같은 말을 여러 번 하는 시간이 줄고, 같은 학부모가 다시 전화하지 않습니다."* |

### 어떻게 파는가 — 0단계는 파는 게 아니다

```
교육비특별회계 (교육감 편성 · 연간)
   ├─ 큰 규모 → 나라장터 공개입찰 → 계약심사
   ├─ 중간   → 제한·지명경쟁
   └─ 소액   → 수의계약 (교육장 위임전결 범위)
```

| 단계 | 무엇 | 계약 |
|---|---|---|
| **0** | **무료 시범** — 교육지원청 1~2곳 | ❌ 없음 |
| 1 | 소액 수의계약 — 교육지원청 | 교육장 결재 |
| 2 | 구축 용역 — 시도교육청 | 교육감 결재 |
| 3 | 연간 유지보수 | 갱신 수요가 구조적 |

> **학생 팀은 사업자 등록 없이는 계약 당사자가 못 됩니다.** 그래서 첫 단계는 계약이 아니라 **사용 실적**입니다.
> 개인정보를 저장하지 않는 설계가 여기서 유리합니다 — **0단계 진입 심사가 가볍습니다.**
>
> **⚠ 수의계약 한도 금액과 발주 시기는 확인하지 못했습니다.** 계약 담당자에게 물으면 답이 나오는 종류입니다.

**기존 서비스** — 복지부 AI·IPSP는 복지부 소관이라 교육청 제도가 없고, 보조금24는 「혜택 조회」이지 절차 안내가 아니며(제출 서류·서식 번호·마감일 없음), 온맘은 게시판입니다. **담당자가 상담 중에 쓰는 도구는 없습니다.**

## 6. MVP와 데모

**강원 · 경남 두 지역** · 발달장애(지적+자폐성) + **발달지체** · 초등 취학과 만 9세 재선정 시점

두 지침 원문을 대조해 서식 번호를 확인한 곳입니다. **나머지 4개 시도는 화면에서 고를 수 없습니다** —
확인하지 않은 서식 번호로 시트를 내지 않기 위해서입니다. `/api/sheet` 도 422로 거부합니다.

### 데모 장면 다섯 개 — 전부 실측 확인

> **1면 「안내 전 확인사항」은 데모 프리셋 7개에서 0건 또는 1건입니다.**
> 뜨면 진짜 봐야 하는 것이고, 안 뜨면 그대로 건네면 됩니다.
>
> ⚠ 조건을 임의로 조합하면 **최대 3건**까지 나옵니다 (30개 조합 실측). 겹치는 조건일수록
> 짚을 것이 늘어나는 것이 맞는 동작입니다. 「어느 조건에서도 1건 이하」라고 말하지 않습니다.

| # | 장면 | 1면에 뜨는 것 |
|---|---|---|
| **1** | 기본 — 자폐성·취학 예정 | **0건.** 「따로 짚을 것이 없습니다. 그대로 건네시면 됩니다」 |
| **2** | **★ 발달지체** | 만 9세에 두 부처의 지원이 같이 끝납니다 *(문서에서 찾음)* |
| **3** | **★ 어린이집** | 교육청 공문이 가지 않습니다 — 신청 시기를 직접 안내하세요 *(담당자가 말함)* |
| **4** | 온종일교실 이용 중 | 방과후활동서비스 ↔ 온종일교실 (공식 제외 대상) |
| **5** | **★ 지역만 강원 → 경남** | 「장애등급 결정서」라는 서류는 없습니다 + 네 가지가 동시에 바뀜 |

**1번이 먼저 와야 합니다.** 「경고가 없으면 그대로 건넨다」를 본 뒤에 2~4번을 보면 **경고가 뜬다는 것 자체가 신호**라는 게 전달됩니다.

| 5번 — 같은 조건, 지역만 바꿈 | 강원 | 경남 |
|---|---|---|
| 카드 | 마음모아카드 | 특기적성비지원카드 |
| 진단·평가 의뢰서 | 서식 3 | **서식 2** |
| 먼저 떼어 올 서류 | **2종** (기초조사 카드 담임교사용이 학교 몫) | **1종** (기초조사서는 신청처 작성) |
| 1면 경고 | 0건 | **1건 — 「장애등급 결정서」라는 서류는 없습니다** |

> **코드는 그대로이고 데이터만 다릅니다.** 「확장은 개발이 아니라 데이터 교체」를 눈으로 증명하는 장면입니다.
