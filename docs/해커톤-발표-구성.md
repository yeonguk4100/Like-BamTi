# 해커톤 발표 구성 — 파이프라인

**2026-11-28 전국 해커톤.** 발표를 블록 단위 파이프라인으로 짠다. 블록마다 들어가는 것(앞 블록에서 넘겨받는 질문)과
나가는 것(청중이 가져갈 한 문장)을 정해 두고, **블록 하나씩 고쳐도 흐름이 깨지지 않게** 한다.

- 수치의 근거는 [해커톤-발표-근거.md](해커톤-발표-근거.md)가 기준이다. 이 문서에는 수치를 새로 적지 않고 근거 문서의 절을 가리킨다
- 아이디어톤 대본은 [발표-대본.md](발표-대본.md). 살릴 문장은 그쪽에서 가져온다
- **상태** 칸: `초안` → `다듬는 중` → `확정`. 확정된 블록만 리허설 시간을 잰다

## 관점 — 2026-10-17에 바꿨다

| | 이전 | 지금 |
|---|---|---|
| **주제** | 제도가 소관별로 갈라져 있다 | **민원·상담 담당자가 이미 한계다 — 그래서 이 도구가 꼭 필요하다** |
| 「갈라짐」의 자리 | 문제 그 자체 | **담당자 부담이 생기는 원인** (블록 4) |
| 청중이 가져갈 것 | 「제도가 복잡하구나」 | **「담당자를 도와야 하는구나 — 사람을 늘릴 수 없으니 도구로」** |
| 구매자(교육청)의 이유 | 학부모 정보 격차 | **자기 직원(담당자)의 업무 부담 · 민원 · 이탈** |

이유 — 구매자는 교육청이고 사용자는 담당자다. 교육청이 돈을 내는 이유는 학부모 정보 격차보다 **자기 조직의 업무 부담과
민원**에 가깝다(사업 멘토: 「교육청이 민감해하는 수치」). 「갈라짐」은 버리지 않는다 — 담당자가 왜 힘든지 설명하는 원인이다.

## 한눈에

```mermaid
flowchart LR
  B0[0 훅] --> B1[1 담당자는 이미 한계]
  B1 --> B2[2 일은 늘어난다]
  B2 --> B3[3 사람은 못 늘린다]
  B3 --> B4[4 부담은 어디서 오나]
  B4 --> B5[5 해법]
  B5 --> B6[6 데모]
  B6 --> B7[7 신뢰]
  B7 --> B8[8 효과]
  B8 --> B9[9 구매자]
  B9 --> B10[10 확장]
  B10 --> B11[11 닫기]
```

**한 줄 구도:** 담당자는 이미 한계다 → 일은 계속 늘어난다 → 사람은 늘릴 수 없다 → 부담의 큰 몫은 소관 밖 문의와
서류 미비로 되돌아오는 신청이다 → 그래서 **담당자가 설명하지 않아도 되게, 종이가 설명하는 도구** → 실제로 돈다 →
믿을 수 있다 → 줄어든 확인 시간이 담당자를 지킨다 → 교육청이 산다 → 고용까지 이어진다

**구도의 축 (사업 멘토링):** 예산 절감 · 인력 · 현장 문제 · 정책효능감. 표현은 「아 다르고 어 다르다」 —
같은 기능을 **구매자(교육청)가 반응하는 말**로 한다. 대조표는 [근거 문서 맨 위](해커톤-발표-근거.md).

### 1. 담당자는 이미 한계

| | |
|---|---|
| **목적** | 부담이 개인의 문제가 아니라 **공식 조사가 반복해서 보여주는 구조**라는 것 |
| **들어오는 것** | 민원 응대가 스트레스 1위 |
| **나가는 것** | **민원이 본업을 밀어내고, 창구를 만들어도 응대는 사람에게 남는다** |
| **말할 문장** | > 일선 공무원 절반(48.3%)이 민원 때문에 본 업무를 못 한다고 답했고, 그 스트레스는 업무량 자체보다 큽니다. 한국 교사의 학부모 민원 스트레스는 OECD보다 15%p 높고, 특수학급 교사 77%는 특수교육 업무만으로도 과중하다고 답했습니다. 교육청은 통합민원팀을 모두 만들었지만, 민원을 실제로 받는 사람의 60%는 여전히 교사 개인입니다. |
| **화면** | 막대 4개 — 본 업무 지장 48.3 · TALIS 56.9 vs 41.6 · 특수학급 77.0 · 「통합민원팀 100% → 실제 응대 교사 60.3」 |
| **근거** | [근거 ②-4](해커톤-발표-근거.md) KIPA 2024 p.266 · 교육부 2026 방안 p.6 · [근거 ②-3](해커톤-발표-근거.md) TALIS · [근거 ②-2](해커톤-발표-근거.md) 실태조사 표 Ⅴ-61 |
| **보조** | 공무원 업무상 질병 1위 정신질환, 산재의 11배 (인사처 2024) · 특이민원 기관 피해 1위 「다른 업무 지연」 87.9% (권익위) |
| **현장 목소리** | 인터뷰 인용 하나 — 「관할이 아닌 경우에는 홈페이지나 전화번호를 찾아서 안내하고 있다」 ([발표-대본 2번](발표-대본.md)) |
| **연결 →** | 「그런데 일은 줄지 않습니다」 |
| **주의** | 각 수치의 **대상이 다르다** — 48.3%는 기초자치단체 공무원 · TALIS 중학교 교사 · 77%는 겸직 필요 없다고 답한 특수학급 교사 중 · 60.3%는 학교 교원. 「특수교육 담당자의 X%」로 묶어 말하지 않는다 — **센터 상담 담당자를 직접 잰 공식 수치는 없다.** 「이직률」은 말하지 않는다 |

### 4. 부담은 어디서 오나 — 갈라짐

| | |
|---|---|
| **목적** | 부담의 원인을 **사람이 아니라 구조**로 돌린다 — 담당자를 탓하지 않는다. 이전 발표의 주제가 여기로 온다 |
| **나가는 것** | **소관 밖 문의와 서류 미비로 되돌아오는 신청 — 둘 다 「갈라짐」에서 온다** |
| **말할 문장** | > 같은 학부모가 여러 번 전화하는 이유는 제도가 교육·복지·의료로 갈라져 있어서입니다. 센터 관리자 셋 중 둘이 기관 사이를 잇는 제도가 없다고 답했고, 학부모가 지금 받는 정보 지원은 0.5%입니다. 다른 기관 서류 없이 신청이 들어오면 담당자가 되돌려 보내고 다시 받습니다. 정부도 사소한 보완 때문에 서류를 다시 내는 부담을 줄이려 하고 있습니다. |
| **화면** | 세 갈래 소관도 + 만 9세 지점 + 「반송 → 재방문 → 재접수」 고리 |
| **근거** | [근거 ②-2](해커톤-발표-근거.md) 실태조사 표 Ⅵ-41·Ⅴ-41 · [근거 ③](해커톤-발표-근거.md) · [근거 ②-3](해커톤-발표-근거.md) 행안부 직권 보정 · [공식데이터-대조](공식데이터-대조.md) |
| **살릴 것** | ① 공식 원문과 대조했더니 **반송을 부르는 서류 2개가 빠져 있었다** (법정대리인 동의서 · 금융정보 동의서) ② 같은 「치료」를 두 부처가 다르게 덮는다 ③ 만 9세에 두 지원이 같이 끝난다 |
| **연결 →** | 「그래서 담당자가 설명하지 않아도 되게 만들었습니다」 |
| **주의** | 67.8%는 장애영아 부문 관리자 77명. **선정·배치 만족도는 높다(70.9%)** — 「절차가 나쁘다」고 하지 않는다. 반송률 숫자는 없다 — 「잦다」는 인터뷰로만 |
