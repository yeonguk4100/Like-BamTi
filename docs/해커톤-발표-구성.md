# 해커톤 발표 구성 — 파이프라인

**2026-11-28 전국 해커톤.** 발표를 블록 단위 파이프라인으로 짠다. 블록마다 들어가는 것(앞 블록에서 넘겨받는 질문)과
나가는 것(청중이 가져갈 한 문장)을 정해 두고, **블록 하나씩 고쳐도 흐름이 깨지지 않게** 한다.

- 수치의 근거는 [해커톤-발표-근거.md](해커톤-발표-근거.md)가 기준이다. 이 문서에는 수치를 새로 적지 않고 근거 문서의 절을 가리킨다
- 아이디어톤 대본은 [발표-대본.md](발표-대본.md). 살릴 문장은 그쪽에서 가져온다
- **상태** 칸: `초안` → `다듬는 중` → `확정`. 확정된 블록만 리허설 시간을 잰다

## 한눈에

```mermaid
flowchart LR
  B0[0 훅] --> B1[1 수요]
  B1 --> B2[2 제약]
  B2 --> B3[3 현장]
  B3 --> B4[4 원인]
  B4 --> B5[5 해법]
  B5 --> B6[6 데모]
  B6 --> B7[7 신뢰]
  B7 --> B8[8 효과]
  B8 --> B9[9 구매자]
  B9 --> B10[10 확장]
  B10 --> B11[11 닫기]
```

**한 줄 구도:** 수요는 늘었다 → 돈과 사람은 제자리다 → 그 부담이 상담 창구에 몰린다 → 원인은 갈라진 제도와
사람을 거쳐 오는 정보다 → 그래서 **이미 있는 사람의 반송·재문의를 줄이는 도구** → 실제로 돈다 → 믿을 수 있다 →
줄어든 만큼이 예산이고 정책효능감이다 → 교육청이 산다 → 고용까지 이어진다

**구도의 축 (사업 멘토링):** 예산 절감 · 인력 · 현장 문제 · 정책효능감. 표현은 「아 다르고 어 다르다」 —
같은 기능을 **구매자(교육청)가 반응하는 말**로 한다. 대조표는 [근거 문서 맨 위](해커톤-발표-근거.md).

| **보조** | 반복 민원 — 공공 민원 담당자 86%가 특이민원 경험, 유형 1위 「반복 청구」 · 특수학교 교권 침해 중 보호자 몫 20% |

### 5. 해법

| | |
|---|---|
| **목적** | 한 문장 정의. 무엇을 하고 **무엇을 안 하는지** |
| **들어오는 것** | 갈라져 있고 반복된다 |
| **나가는 것** | **조건을 넣으면 어디에·무엇을 들고·언제까지가 한 장으로 나온다 — 판정하지 않는다** |
| **말할 문장** | > 복지그루는 상담 중 아이 조건을 넣으면, 어디에 무엇을 들고 언제까지 가야 하는지를 한 장으로 정리해 학부모에게 그대로 건네게 합니다. 담당자는 설명하지 않아도 됩니다. 설명은 종이가 합니다. |
| **아 다르고 어 다르다** | 「업무를 줄여 준다」가 아니라 **「사람을 늘릴 수 없는 자리에서, 이미 있는 사람의 반송·재문의를 줄인다」** |
| **연결 →** | 「직접 보여드리겠습니다」 |
