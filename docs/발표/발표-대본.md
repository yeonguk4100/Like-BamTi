# 복지그루 해커톤 발표 대본

2026-11-12 · [복지그루-해커톤-발표.pptx](복지그루-해커톤-발표.pptx) 20장. 같은 대본이 슬라이드마다 **발표자 노트**에도 들어 있다.
발표자료 제출 마감은 **11/23**이다.

**순서** — 서비스 소개 → 문제 제기(가장 길다) → 해결 방안 → 시연(랜딩 + 서비스) → 추후 발전 방향 → 팀원 소개 → Q&A

- 통계 슬라이드는 **원문 해당 부분(형광펜)을 크게** 보여 주고, 출처는 **아래 한 줄**(누르면 원문 링크)로 단다 — 2026-11-12 링크 화면 캡처는 뺐다
- 숫자를 말할 때 대상을 함께 말한다 — 슬라이드 아래 「대상」 줄
- 말하는 시간 약 7분 30초 + 시연 영상 2~3분
- **6번은 A안 · B안 두 장이 들어 있다 (PPT 6 · 7번).** 하나를 지우면 7번부터 번호가 대본과 맞는다
- 2026-11-12 수정: 「학부모 전화 한 통」 고리 슬라이드를 뺐고(너무 많다), 추후 발전 방향에서 **기업용 버전**을 4장으로 키웠다. 5번에 특이민원 뜻을 넣고, 7~9번을 「대상자 · 일은 늘고 → 사람은 기준만큼 못 늘고 → 돈은 제자리」로 다시 짰고, 기술(13) 다음에 바로 시연(14)이 오게 순서를 바꿨다
- 8번 계산: 특수교육법 시행령 제22조 「특수교육 담당 교사는 학생 4명마다 1명」(법제처 원문 확인 2026-11-12) · 법 제27조 학급 정원 초·중 6명. 학생 수는 특수학교 31,993 + 특수학급 72,784 = 104,777명(연차보고서 표 1·2). **4,700명은 우리가 한 단순 계산이지 공식 부족 인원이 아니다**
- 8번 과밀(2026-11-12 슬라이드에서 뺐다 — 질문 대비로만): 교육부 보도자료 「2025년 특수교육기관 과밀학급 크게 감소」(2025-04-08) — 2022 8.8% → 2023 9.9% → 2024 10.1%(1,882학급) → 2025 3.8%, 인천 2024 17.3%. 교육부도 「기간제 교원 임용을 지원하여 특수교사 부족 문제」를 메웠다고 썼다
- 8번 인천 반 인원: **공식 원문에서는 확인하지 못했다.** 언론은 진상조사 결과보고서를 인용해 「정원 6명 학급에 8명」이라고 전한다(한국교육신문) — 기사라 슬라이드에는 넣지 않는다
- 8번 인천: 인천광역시교육청 보도자료(2025-08-13) — A초 특수교사 사망 사건 관련 「과밀 특수학급 증설」의 특수교육법 위반 여부로 감사원 공익감사 청구. **「교사 1명에 학생 10명」은 공식 원문에서 확인하지 못해 넣지 않았다**
- ⚠ **「사람이 안 늘었다」고 말하지 않는다.** 교원 수는 18,772명('16) → 29,773명('26)으로 늘었다(연차보고서 표 1·2). 말할 수 있는 것은 「법정 기준만큼 못 늘었다(목표 82%)」와 「1인당 특수교육비가 전년보다 899천 원 줄었다」다
