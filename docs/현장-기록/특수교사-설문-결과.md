## 읽은 것

1. **특수교사에게는 「같은 질문 반복」이 0명이다.** 반복 문의는 센터 · 교육지원청 창구에 몰리는 것으로 보인다
   (인터뷰 ①② 와 같은 방향). 교사 설문으로 「반복 전화」를 말하지 않는다
2. **교사의 부담은 「찾고 · 비교하고 · 맞는지 확인」이다** — Q10 비교 5 · Q14 한곳에서 3 · Q13 누리집은 2명만 본다.
   안내가 서로 달라 다시 확인한 사람도 2명(Q11 · Q12)
3. **필수 조건이 설계 원칙과 그대로 겹친다** — 출처 5 · 검토·수정 5 · 개인정보 없이 4.
   「규칙이 고르고 근거를 붙이고 판정하지 않는다」를 현장이 먼저 요구한 셈
4. **AI가 빠뜨릴까 걱정한다** (Q21) — 「제도는 규칙이 고르고 AI는 문장만」이 답이다.
   전체 조합 2,200개 점검(`scripts/check-rules.py`)을 함께 보여 준다
5. **시범 기준은 「자료 확인 시간」(5명)** — 시범 운영 KPI 첫째로 둔다
6. 「지금 방식이 더 편하다」 · 「보조하기 어렵다」는 **0명**
