# 해커톤 발표 뼈대 — 「담당자가 이미 한계다」

2026-11-09 · 전국 해커톤(11-28)용. 기술은 한 줄로 줄이고 **스트레스 → 이직 → 예산**을 축으로 간다.
수치는 [발표 근거](해커톤-발표-근거.md)에 있는 공식 원문만 쓴다. **숫자를 말할 때 대상을 함께 말한다.**

## 흐름

```
문제 (1~5)          해결 (6~7)           사업 (8~10)
장면 → 스트레스 →    현장 확인 →          예산 절감 → 누가 사나 →
반복 → 이직 →        해결 + 시연           추후 방향 → 마무리
못 늘린다
```

## 블록

| # | 블록 | 할 말 | 근거 (대상 · 출처) |
|---|---|---|---|
| 1 | **장면** | 「학부모 전화 한 통이 담당자에게 어떻게 돌아오는지 보겠습니다」 | 수원 센터 인터뷰 — 서류 없이 와서 되돌려 보내고 다시 받음 |
| 2 | **스트레스** | 「교원이 꼽은 스트레스 1위는 학부모 민원입니다」 | **83%** — 교원 10,888명 (인권위 2024) · 한국 **56.9%** vs OECD 41.6% — 중학교 교사 (TALIS 2024) |
| 3 | **반복** | 「같은 요구가 반복되고, 그 때문에 본 업무가 밀립니다」 | 반복 청구 **70.9%** · 정신적 스트레스 **90.8%** — 공공 민원 담당자 (권익위 2025) · 본 업무 지장 **48.3%** — 기초자치단체 공무원 (KIPA 2024) |
| 4 | **이직** | 「그래서 떠나려 합니다」 | 이직 고려 **46.3%** · 특수학교 **37.5%** — 교원 (인권위 2024) · 교육 국가공무원 퇴직 12,228명 중 의원면직 **6,476명** (인사처 2025) |
| 5 | **못 늘린다** | 「그런데 사람도 돈도 제자리입니다」 | 특수교육 예산 비중 **10년째 4%대** · 강원 **3.1% 전국 최저** · 법정 정원 확보 목표 **82%** · 센터 교사 1,740명이 신청 52,005건 (1명당 약 30건) |
| 6 | **현장 확인** | 「처음엔 학부모용이었습니다. 인터뷰해 보니 질문이 모이는 곳은 담당자 책상이었습니다」 | 아래 6번 상세 |
| 7 | **해결 + 시연** | 「조건을 넣으면 학부모가 한 번에 갖춰 오게 하는 한 장이 나옵니다」 | **시연 영상** — 조건 입력 → 확인사항 → 안내문 □ → 접수 누락 확인. 기술은 「규칙이 고르고 AI는 문장만 · 저장하지 않음」 한 줄 |
| 8 | **예산 절감** | 「반송 1건이 줄면 담당자 시간이 그만큼 돌아옵니다」 | 줄어든 반송·재문의 건수 × 1건당 처리 시간 × 인건비 → **시범 운영에서 실측** |
| 9 | **누가 사나** | 「교육청 1곳이 도입하면 산하 교육지원청 전부가 씁니다. 사람을 뽑지 않고 부담을 줄이는 방법입니다」 | B2G · 교육지원청 1곳 시범부터 |
| 10 | **추후 방향** | 「학교 안에서 학교 밖으로」 | 아래 10번 상세 |
| 11 | **마무리** | 「반복 확인을 줄여 학부모와 직접 상담할 시간을 늘립니다. 최종 수혜자는 학생과 학부모입니다」 | — |

### 6. 현장 확인 — 학부모용에서 담당자용으로

| 순서 | 할 말 | 근거 |
|---|---|---|
| 처음 | 「학부모가 직접 찾아보는 서비스를 생각했습니다」 | — |
| 인터뷰 | 「교육청 · 특수학교 등 20곳에 묻고 2곳은 깊이 인터뷰했습니다」 | [기관 문의 기록](현장-기록/기관-문의-기록.md) |
| ① | 「학부모는 소관을 모르고 한 곳에 다 묻습니다」 | 수원 센터 Q1 — *"소관이 아닌 복지 관련 내용까지 함께 문의"* |
| ② | 「혼자 찾으면 틀린 안내를 받기도 합니다」 | 수원 센터 — 주민센터 오안내 사례 |
| ③ | 「결국 담당자에게 다시 전화가 옵니다」 | 인터뷰 ① — *"정보 부족하면 재요청 드리고 담임 선생님께 여쭤봄"* |
| 전환 | 「그래서 도구는 담당자가 쓰고, 학부모는 담당자가 건네는 한 장을 받습니다」 | → 7번 |

> 한 줄: **학부모에게 앱을 주면 다시 전화가 옵니다. 담당자에게 도구를 주면 학부모는 한 번에 갖춰 옵니다.**

### 10. 추후 방향 — 학교 안에서 학교 밖으로

| 단계 | 할 말 | 근거 |
|---|---|---|
| ① 지역 | 「강원 · 경남에서 나머지 시도로 넓힙니다. 절차는 같고 이름 · 서식만 다릅니다」 | 6개 시도 지침 대조 |
| ② 알림 · 체크 | 「기한 알림을 붙이되 연락처는 저장하지 않습니다 — 안내문 QR로 학부모 휴대폰 캘린더에만」 | 저장하지 않는 원칙 유지 · 체크(안내문 □ · 접수 누락 확인)는 이미 시연에 있음 |
| ③ 졸업 뒤 · 기업 | 「다음은 고용 쪽 지원제도를 같은 방식으로 정리합니다」 | 특수교육대상 고교 졸업생 취업률 **22%** (e-나라지표 2026) · 미고용 기업 **73.8%** 「시킬 직무를 찾기 힘들다」 · 발달장애인 평균 근속 **3년 10개월** (고용개발원 2025) |

## 지킬 선 — 질문에서 막히는 곳

| 하지 말 것 | 이유 · 대신 |
|---|---|
| 「이직률이 높다」 | 특수교사 이직률 공식 통계 없음. 「중도퇴직 3.3배」도 언론 보도뿐 → **「이직 고려 46.3%」 · 「의원면직 6,476명」** |
| 「○억 원 절감」 | 반송률 공식 통계 없음 → **계산식 + 시범에서 실측** |
| 「안내문으로 해도 다시 온다」 | 우리 해법을 부정하게 들림 → **「학부모용 앱으로는 다시 온다」**(6번)로 |
| 「장애인 이직률이 높다」 | 기업 조사에서 「낮다」 52.4% → **근속이 짧다 · 직무를 못 찾는다** |
| 「담당자를 대신한다」 | 일자리를 줄인다는 뉘앙스 → **「반복 확인을 줄여 상담 시간을 늘린다」** |
| 대상 섞기 | 2~4번은 교원 · 중학교 교사 · 공공 민원 담당자로 제각각 → 슬라이드에 대상 표기 |
| 20곳 내역 단정 | 유형별 곳 수 · 인터뷰 ① 기관명 미기록 → **「심층 2곳에서 같은 이야기」**까지만 |

## 아직 채울 것

- 시연 영상 녹화
