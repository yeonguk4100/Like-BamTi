# 기획 고도화 — 강원·경남 선정·배치 지침 분석

분석일 2026.08.18
자료 ① 「강원특별자치도 특수교육대상자 선정·배치 업무 길잡이」 (강원특별자치도교육청·강원특수교육지원센터)
자료 ② 「2025 특수교육대상자 선정·배치 업무 처리 지침」 (경상남도교육청, 132쪽)

> **이 문서는 기획서가 아니라, 두 지침을 읽고 무엇이 확정됐고 무엇을 바꿔야 하는지 정리한 작업 문서입니다.**

---

## 1. 확정된 것 — 구조도의 물음표가 지워졌다

기존 기획서 2.4에서 "공개 자료로 복원했으며 현장 확인 필요"라고 적었던 항목이 **두 지역 공식 지침으로 확인**됐습니다.

| 기존 물음표 | 결과 |
|---|---|
| 진단·평가 30일이 실제 기한인가 | ✅ **확정.** 양 지역 모두 "회부받은 날로부터 30일 이내" 명시 (특수교육법 제16조) |
| 결정 통보 2주가 실제 기한인가 | ✅ **확정.** 양 지역 모두 "진단·평가 결과보고 후 2주 이내" |
| 교육과 복지 중 순서가 있는가 | ✅ **없다.** 별개 트랙임이 확인됨 (3-①) |
| 지역마다 절차가 다른가 | ✅ **절차는 같고 명칭·서식·일정만 다르다** (2장) |

### 절차 대조 — 두 지역이 같다

| 단계 | 강원 | 경남 |
|---|---|---|
| 의뢰 | 본인·보호자 또는 학교장 → 교육지원청 | 보호자 또는 학교장(보호자 동의) |
| 회부 | 교육장 → 지역특수교육지원센터 (즉시) | 교육감·교육장 → 특수교육지원센터 |
| 진단·평가 | 지역 진단·평가팀, **30일 이내** | 특수교육지원센터, **30일 이내** |
| 심사 | 시·군 특수교육운영위원회 | 시·군 운영위(영유초중) / 도 운영위(고) |
| 통보 | **결과보고 후 2주 이내** | **최종의견 통지 후 2주 이내** |
| 관할 분리 | 영유아·초·중 = 교육지원청 / **고 = 도교육청** | 영유아·초·중 = 교육지원청 / **고 = 도교육청** |

**다른 것은 서식 번호와 명칭뿐입니다.** (진단·평가 의뢰서: 강원 [서식 3] / 경남 [서식 2])

> ## 💡 **이것이 확장 가능성의 실증입니다.**
> 기획서 12장에서 *"구조는 동일하고 데이터만 교체하면 된다"*고 **주장**했는데, 이제 **두 지역 공식 문서로 대조해서 보여줄 수 있습니다.** 추정이 아니라 확인입니다.
>
> 발표에서 이렇게 말할 수 있습니다 — *"강원과 경남 지침을 대조했습니다. 절차는 동일하고 서식 번호와 지역 제도 명칭만 다릅니다. 그래서 지역 확장은 데이터 교체입니다."*

## 2. 발견 ① — 교육청 **내부**에서도 정보가 안 흐른다

강원 지침 「선정·배치 유의사항」에 이 문장이 있습니다.

> ### ◼ 특수교육대상자 선정·배치 담당자는 배치 결과를 **반드시 치료업무, 방과후업무 담당자에게** 배치 결과를 **공유**하여 **마음모아카드 부정사용 예방**

**세 가지를 동시에 말해 줍니다.**

| 읽히는 것 | 의미 |
|---|---|
| 선정·배치 담당 / 치료 담당 / 방과후 담당이 **다른 사람이다** | 같은 교육지원청 안에서도 업무가 쪼개져 있음 |
| 지침에 **"반드시 공유하라"**고 써야 했다 | **지금 자동으로 흐르지 않는다는 뜻** |
| 이유가 **"부정사용 예방"**이다 | 정보 미공유가 실제 사고로 이어진 적이 있다 |

> ## 🔥 **기획서의 문제 정의를 넓힐 수 있습니다.**
>
> 지금까지는 **"부처가 달라서"**라고만 말했습니다. 이제 **"같은 교육청 안에서도 담당자가 갈려서"**를 추가할 수 있고, **근거가 정부 공식 문서**입니다.
>
> 그리고 이건 가상 페르소나가 아닙니다. 멘토가 지적한 *"담당자가 실제로 그러는지 검증이 필요하다"*에 대해, **인터뷰 없이 낼 수 있는 1차 증거**입니다.

**발표 문장 후보**

> *"저희가 지어낸 이야기가 아닙니다. 강원도교육청 지침에 '배치 결과를 반드시 치료·방과후 담당자에게 공유하라'고 적혀 있습니다. **지침에 적어야 했다는 건 지금 안 되고 있다는 뜻입니다.**"*

**⚠ 확인 필요** — 마음모아카드의 정확한 지원 범위(치료지원·방과후학교 대상 여부, 금액, 신청 절차). 지침 본문에서는 명칭만 등장합니다.

## 3. 발견 ② — 진짜 문제는 신규 신청이 아니라 **재선정 마감**이다

두 지침 모두, **이미 선정된 아동이 날짜를 놓치면 지원이 끊기는 구조**를 반복해서 경고합니다.

| 대상 | 언제 다시 해야 하나 | 놓치면 |
|---|---|---|
| **발달지체** | **만 9세 생일 전에 재진단·재선정** | 해당 학년도까지만 유지 후 **방과후학교·치료지원 종료** |
| **건강장애** | **매년, 매 학년도 말까지 재심사 신청** | 재선정 실패 |
| **학습장애** | 중학교 진학 시 재선정 | 재선정 실패 |
| **정서·행동장애** | 중학교 진학 시 재선정 | 재선정 실패 |
| 재취학 대상 | 학교장·교육장이 **12월 말**에 보호자 확인 | 다음 학년도 누락 |

강원 지침의 예시가 특히 구체적입니다.

> *"9세가 되는 생년월일이 2026. 3. 14.일 경우 → 2026. 3월 말일까지 유지 후 종료"*

그리고 담당자 업무로 이렇게 적혀 있습니다.

> *"매년 발달지체 대상자로 선정된 학생을 **파악하여** 학교 및 보호자에게 재심사 안내"*

> ## 🔥 **이게 지금 담당자가 손으로 하고 있는 반복 업무입니다.**
>
> - 대상자 명단은 **이미 교육청이 갖고 있습니다** (신규 발굴이 필요 없음)
> - 마감일은 **생년월일에서 기계적으로 계산됩니다** (만 9세 도래월)
> - 놓치면 **받고 있던 지원이 끊깁니다** (손실이 확정적)
> - **지침에 담당자 의무로 명시돼 있습니다** (새 업무가 아니라 기존 업무)

## 5. 발견 ④ — 지침의 Q&A가 **담당자의 실제 질문 목록**이다

두 지침 모두 뒤쪽에 Q&A 장을 두고 있습니다. **이건 담당자가 반복해서 묻는다는 뜻입니다.** 그리고 두 지역에서 겹치는 질문이 있습니다.

| 겹치는 질문 | 강원 | 경남 |
|---|---|---|
| **"기초 상담 시 필요한 정보와 안내사항은?"** | ✅ | ✅ |
| 특수학교 없는 지역 → 타지역 배치 | ✅ | ✅ |
| 과연령자 선정 | ✅ | ✅ |
| 이사·전학 (타시군 / 타시도) | ✅ | ✅ |
| 취학 유예 | ✅ | ✅ |
| 가정폭력 비밀전학 시 조치 | ✅ | ✅ |

경남에만 있는 질문 중 결정적인 것:

> ### **Q: 특수교육대상자 선정 희망 학생 상당수가 이미 보건복지부에 장애인 등록이 되어 있습니다. 장애인으로 (등록되면 자동으로 선정되나요?)**

> ## 🔥 **담당자조차 "복지 등록과 교육 선정이 별개냐"를 묻습니다.**
> 우리 기획의 핵심 주장 — **두 트랙이 따로 흐른다** — 을 정부 지침이 Q&A로 다루고 있다는 뜻입니다. 이보다 강한 근거는 없습니다.

그리고 **첫 번째 질문이 우리 도구의 정의와 같습니다.**

> *"기초 상담 시 필요한 정보 및 안내사항에는 어떤 것들이 있을까요?"*
> → **이 질문의 답을 한 화면으로 만드는 것이 이 서비스입니다.**

## 7. MVP 재검토 — 취학 전환 vs **재선정 마감 관리**

멘토는 "초등 취학 전환 하나"를 제안했고 현 기획서도 그렇게 잡혀 있습니다. **그런데 지침을 읽고 나니 더 강한 후보가 생겼습니다.**

| | A. 취학 전환 (현재 안) | B. **재선정 마감 관리** (신규 안) |
|---|---|---|
| 대상 파악 | 신규 발굴 필요 | **명단이 이미 교육청에 있음** |
| 마감일 | 시도별·연도별로 다름, 확인 필요 | **생년월일에서 기계적으로 계산** (만 9세) |
| 놓쳤을 때 | 다음 해에 다시 시도 가능 | **받던 지원이 끊김 — 손실 확정** |
| 담당자 업무와의 관계 | 새 업무가 될 수 있음 | **지침에 명시된 기존 의무** ("매년 파악하여 안내") |
| 효과 측정 | 상담 20~30건 필요 | **재선정 누락 0건 = 첫 해에 셈** |
| 데모 난이도 | 제도 10~15개 정리 필요 | **날짜 계산 + 알림. 훨씬 단순** |
| 걸림돌 | — | ⚠ **아동 명단을 다루므로 개인정보 부담이 큼** |

### 권고 — **B를 진입점으로, A를 본체로**

둘 중 하나를 고르는 문제가 아닙니다. **순서 문제입니다.**

```
  ① 재선정 마감 관리 (진입)          ② 상담 확인 시트 (본체)
     "놓치면 끊긴다"                    "무엇을 확인해야 하나"
     날짜 계산 · 손실 방지               제도 목록 · 근거 · 안내문
              └──────── 같은 제도 DB를 쓴다 ────────┘
```

**이유 세 가지**

1. **①은 "왜 사야 하나"에 즉답합니다.** *"발달지체 아동이 9세 생일에 지원이 끊기는데, 지금은 담당자가 손으로 명단을 훑습니다"* — 구매 이유가 한 문장입니다
2. **①은 담당자 업무를 늘리지 않습니다.** 지침이 이미 시키는 일이고, 우리는 그 일을 자동화하는 것입니다. 멘토가 지적한 함정을 정면으로 피합니다
3. **①과 ②는 같은 데이터를 씁니다.** 제도별 요건·기한 DB 하나로 둘 다 굴러갑니다

**⚠ 단, ①은 개인정보 부담이 ②보다 훨씬 큽니다.** 아동 명단을 다루기 때문입니다. **데모는 가상 명단으로 만들고, 실제 도입 시 처리 구조는 별도 설계**한다고 명시해야 합니다.
