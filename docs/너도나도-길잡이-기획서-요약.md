# 너도나도 길잡이

**특수교육 지원제도 상담 지원 도구**

**담당자가 학부모 문의를 3분에 끝내게 하는 업무 도구** · 업무 효율화 트랙 · 2026.08

> 기관 담당자가 학부모 문의를 받았을 때 아동의 **거주지·장애유형·연령**을 입력하면, 확인해야 할 제도와 **마감일·준비서류·근거 법령**을 한 장으로 정리해 주고, **학부모에게 그대로 건넬 안내문**까지 함께 만들어 주는 도구.

---

## 1. 문제

아이에게 장애가 있다는 것을 막 알게 된 부모는 **무엇부터 해야 하는지 모릅니다.** 그래서 기관에 전화합니다. 그런데 전화를 받은 담당자도 **전부 파악하거나 달라진 제도들을 파악하기엔 어렵습니다.**

지원제도가 **교육·복지·의료·고용 네 갈래**로 나뉘어 소관 부처가 다르기 때문입니다. 담당자는 자기 소관만 알고, 나머지는 그 자리에서 검색해 답합니다. **한 통의 전화가 길어지고, 그러고도 빠지는 제도가 생길 수 있습니다.**

| 영역 | 소관 | 신청처 |
|---|---|---|
| 진단·평가, 학교 배치, 치료지원 | **교육청** | 특수교육지원센터 |
| 장애 진단·등록 | 복지부 (의료기관 경유) | 병원 → 읍면동 |
| 발달재활, 방과후활동, 주간활동 | 복지부 | 읍면동 / 발달장애인지원센터 |
| 취업·직업재활 | 고용노동부 | 고용센터 |

여기에 **지역마다 조례와 자체사업이 달라** 이사하면 지원이 바뀝니다.

### 얼마나 큰 문제인가

| 근거 | 수치 |
|---|---|
| 특수교육대상자 | **120,735명 (2025).** 학령인구는 10년간 −15%인데 대상자는 **+37%** ▲ |
| 복지 사각지대 발생 원인 1위 | **대상자 비신청 45.7%**, 그 이유 중 **"몰라서" 70.9%** (복지 담당 공무원 인식 조사) |
| 발달장애 부모 인지도 | 주요 정책조차 **3명 중 2명이 존재를 모름** (국가인권위·부모연대, 1,174명) |
| 접점 | 대상자의 **74.1%가 특수학교가 아닌 일반학교.** 그 특수교사에게도 복지는 소관 밖 |

`[출처]` [뉴스핌](https://www.newspim.com/news/view/20260710001213) · [복지로](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/news/news/6667249.html) · [비마이너](https://www.beminor.com/news/articleView.html?idxno=20498)

> **제도는 만들어졌는데 자세한 정보를 찾기엔 많은 시간이 필요합니다.**

## 2. 신청 절차 — 두 트랙이 따로 흐른다

```
      [교육 트랙 — 교육청]                 [복지 트랙 — 복지부]

  ① 조기 발견 / 선별검사                ① 병원 진단 · 진단서
  ② 진단·평가 의뢰                      ② 장애 정도 심사 · 등록
  ③ 특수교육지원센터 진단·평가 (30일)    ③ 발달재활서비스 신청 (소득 심사)
  ④ 특수교육운영위원회 심사 (2주)        ④ 바우처 발급 → 제공기관 (대기)
  ⑤ 선정·배치 통보                      ⑤ 방과후활동 등 신청
  ⑥ 학교 배치 · 개별화교육계획
```

`[근거]` 장애인 등에 대한 특수교육법 제14~17조 · 장애아동복지지원법 제21조

**두 트랙은 서로를 정확히 모릅니다.** 그래서 부모는 아래 지점에서 막히고, 그때 기관에 전화합니다.

| 막히는 지점 | 부모의 질문 | 지금 누가 답하나 |
|---|---|---|
| 교육 ① ↔ 복지 ① | *"진단을 어디서 먼저 받아야 하나요?"* |
| 교육 ⑥ ↔ 복지 ⑤ | *"방과후는 학교 것과 복지 것 중 뭘 받나요?"* | **양쪽 다 소관 밖** |
| 이사 | *"전에 받던 걸 여기서도 받나요?"* | **지역마다 다름** |

> **아래 두 줄이 이 서비스의 존재 이유입니다. 한 기관이 답할 수 없는 질문이 실재합니다.**

**⚠ 이 구조도는 법령으로 복원한 것입니다.** 법정 기한(30일/2주)이 실무에서 지켜지는지, 취학 전환 시 실제 마감 시기가 언제인지는 **아직 확인하지 못했습니다.** 이 물음표가 곧 담당자 인터뷰 질문지입니다.

## 3. 누가 쓰고, 누가 돈을 내는가

| | 누구 | 무엇을 |
|---|---|---|
| **사용자** | 기관 담당자 (특수교육지원센터·복지관·가족지원센터) | 상담하면서 조건을 입력 |
| **수혜자** | 학부모 | 개인화된 안내문을 받음 |
| **최종 수혜자** | 아동 | 되돌릴 수 없는 시기를 놓치지 않음 |
| **구매자** | **교육청 / 교육지원청** | 도입 결정과 예산 집행 |

**쓰는 사람, 혜택 보는 사람, 돈 내는 사람이 전부 다릅니다.** 부모용 안내문은 무료이고, 수익은 기관에서 받습니다.

**부모를 직접 사용자로 두지 않는 이유** — ① 정보에 접근할 줄 아는 부모에게만 도달해 격차가 재생산됩니다 ② 취약계층에 과금하는 구조가 됩니다.

## 4. 무엇을 하는가

```
  학부모 문의 ─▶ 담당자 ─▶ [ 이 도구 ] ─┬─▶ ① 담당자용 확인 시트
                                        └─▶ ② 학부모용 안내문
```

**① 담당자용 확인 시트** — 확인할 제도(부처 무관) · 신청 마감일 · 준비 서류 · 근거 법령·조례 링크 · 조건이 겹치는 항목에 ⚠ 표시
**② 학부모용 안내문** — 같은 내용을 부모가 읽을 문장으로. 출력해서 건네거나 문자로 발송

### 판정하지 않습니다. 확인 목록을 줍니다.

| ❌ 하지 않음 | ✅ 대신 |
|---|---|
| "이 아동은 방과후활동 대상입니다" | "방과후활동을 확인하세요. 요건은 이것, 근거는 여기입니다" |
| "이 조합은 중복이라 불가합니다" | "⚠ 중복 제한이 있을 수 있습니다. 사업안내 ○조를 확인하세요" |
| 서류를 대신 작성·제출 | 준비 서류 목록과 서식 위치를 안내 |

세 가지 이유입니다. ① 입력 세 가지로 자격을 확정할 수 없습니다(소득·재산·장애 정도·기존 수급 이력 필요) ② 잘못된 확정 안내는 실제 피해가 됩니다 ③ 서류 작성·제출 대행은 **행정사법**이 정한 영역입니다.

### 담당자의 업무가 늘지 않는 설계

새 도구는 대개 새 입력 업무를 만듭니다. 그래서 이렇게 막았습니다.

- **입력은 상담 첫머리에 어차피 묻는 것만** (거주지·장애유형·연령)
- **결과물이 그 자리에서 나온다** — 나중에 다시 들어올 일이 없음
- **진행 상태 관리는 넣지 않는다** — 매일 갱신해야 살아 있는 기능은 유지되지 않음
- **기록은 부산물로 남는다** — 생성한 안내문이 곧 안내 기록

> **판매 논리는 "시간 절약"이 아니라 "누락 방지와 기록"입니다.** 시간 절약은 증명해야 하지만, 무엇을 안내했는지 근거와 함께 남는다는 것은 **도입 즉시 참**입니다.

### AI를 쓰는 지점

| 단계 | AI 역할 | 왜 AI인가 |
|---|---|---|
| 제도 데이터 구조화 | 조례·사업안내에서 대상·요건·신청처·기간·서류 추출 | 지자체마다 문서 형식이 달라 규칙 파싱 불가 |
| 안내문 생성 | 확인 시트를 학부모용 문장으로 변환 | 담당자별 안내 품질 편차 해소 |
| ❌ 자격 판정 | **쓰지 않음** | 위 참조 |

**AI를 빼면 남는 것** — 지역별 제도 구조화 DB, 제도 간 관계 정보, 안내 이력. **자산이 남습니다.**
**사람이 손으로 못 하는 이유** — 1회 정리는 됩니다. 매년 개편분을 다시 구조화하는 것은 못 합니다. 온맘에 2022년 자료가 남아 있는 이유가 그것입니다.

## 5. 경쟁과 차별점

| 서비스 | 성격 | 한계 |
|---|---|---|
| **복지부 AI 정책실험실** | 복지공무원 업무지원 AI (경기 5개 시 실증, 전국 확산 예정) | **복지부 소관 = 교육청 제도 없음** |
| **개인별지원계획(IPSP)** | 발달장애인지원센터 법정 사업. 담당자가 서비스 조합을 계획서로 작성 | 복지부 소관, 대기 발생, **교육청 제도 미포함** |
| **보조금24** | 중앙+지자체 혜택 6,774개 맞춤 안내 | 교육청 제도 없음, **마감일·중복 제한 없음** |
| **온맘** (국립특수교육원) | 생애주기별 제도 **게시판** | 거주지 입력·확인 기능 없음, **2022년 게시물 잔존** (2026.08 직접 확인) |

**전부 부모용 조회 서비스이거나 복지부 소관입니다. 담당자가 상담 중에 쓰는 도구는 없습니다.**

### 남는 빈틈

1. **교육과 복지를 한 화면에서 본다** — 부처가 달라 아무도 못 함
2. **담당자가 상담 중에 쓰는 도구다** — 전부 부모용 조회 서비스
3. **마감일과 전환 시기를 말한다** — 전부 "지금 받을 수 있는 것" 목록

> **"부처가 달라서 정부도 못 한다"는 진입 기회이지 진입장벽이 아닙니다.**
> 장벽은 ① 검증된 교육×복지 통합 데이터 ② **매년 개편분을 반영하는 갱신 체계** ③ 제도 간 관계 정보 ④ 축적된 안내 이력에서 만들어집니다. **②는 비용이자 동시에 장벽이며, 갱신을 구독료의 근거로 전환합니다.**

*(지역 반영은 차별점이 아닙니다 — 보조금24가 지자체 혜택 6,774개를 이미 커버합니다.)*

## 6. 사업 모델

| 순위 | 대상 | 근거 |
|---|---|---|
| **1** | **시도교육청 / 교육지원청 구축 용역** | 구매 결정 주체가 명확하고 시스템 용역 조달 경로 존재. 1개 시도 검증 후 횡전개 |
| 2 | 연간 유지보수 (구축비의 10~15%) | 제도가 매년 개편되므로 갱신 수요가 구조적으로 발생 |
| 3 | 장애인가족지원센터·복지관 | 민간 위탁이라 자체 예산 가능성 |
| — | 발달장애인지원센터 | 복지부 소관 — IPSP·복지부 AI와 정면 경합. 후순위 |

**개별 센터 단위 구독은 하지 않습니다.** 특수교육지원센터는 교육지원청 소속으로 독립 구매 주체가 아닙니다.

**구매 이유 세 가지** — ① 소관 밖 제도 **누락 방지** ② 무엇을 안내했는지 **기록** ③ 담당자가 바뀌어도 안내가 유지되는 **품질 균일화**(순환보직 구조에 대한 직접 대응)

**⚠ 이 장 전체가 검증 대상입니다** — 구매 결정권자·예산 항목·조달 절차·개인정보 요건을 아직 확인하지 못했습니다.

## 7. MVP와 측정

| 항목 | 범위 |
|---|---|
| 지역 · 대상 | 강원 1개 시(원주 또는 춘천) · 발달장애(지적+자폐성) |
| 전환 시점 | **초등 취학 하나** |
| 제도 수 | **10~15개, 수작업으로 정확하게** |
| 화면 | 조건 입력 → 확인 시트 → 학부모용 안내문 |
| 만들지 않는 것 | 실시간 크롤링, 공적 데이터 연계, 자격 최종 판정, 진행 상태 관리 |

**핵심 데모** — 한 번 입력하면 두 장이 나오는 화면. 왼쪽 담당자용 시트, 오른쪽 학부모용 안내문. **부처가 섞인 목록이 한 화면에 있다는 것 자체**가 차별점의 증거입니다.

| 지표 | 언제 측정되나 |
|---|---|
| **안내문 1장에 포함된 타 부처 제도 수** | **첫 사용 즉시** |
| **담당자가 몰랐던 제도가 목록에 있었는가 (누락 발견 건수)** | **첫 사용 즉시** |
| 안내문 작성 소요 시간, 담당자의 안내 수정률 | 상담 20~30건 (10월 이후) |

> 나머지 지표는 증명에 몇 달이 걸립니다. **위 두 개는 첫 안내문 한 장에서 셉니다** — 그리고 그게 차별점 1의 직접 증거입니다.
