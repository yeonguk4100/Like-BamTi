# 제도 출처 지도 — 서울 제외 16개 시도

지역마다 다른 장애아동 지원제도를 **어디서 · 언제 · 어떤 형식으로** 받는지 정리한 지도.
갱신을 어떻게 돌리는지는 [데이터-갱신-파이프라인.md](데이터-갱신-파이프라인.md)에 있다.

- **조사일** 2026-10-16 · 각 교육청 누리집과 첨부 원문(pdf · hwp · hwpx)을 직접 열어 확인했다. 언론·블로그는 쓰지 않았다
- **「미확인」은 확인하지 못했다는 뜻이다.** 추정으로 채우지 않는다
- 금액은 **2026학년도 원문 기준**이다. 해마다 바뀐다
- 구현(화면에서 고를 수 있음)은 **강원 · 경남**뿐이다. 나머지는 출처만 확인했다

## 1. 제도는 네 층이고, 층마다 출처가 다르다

| 층 | 예시 | 출처 | API | 원본 갱신 | 우리 쪽 연결 |
|---|---|---|---|---|---|
| **① 중앙부처 복지** (전국 공통) | 발달재활 · 장애아동수당 · 방과후활동 | 한국사회보장정보원 「중앙부처복지서비스」 ([15090532](https://www.data.go.kr/data/15090532/openapi.do)) | ✅ XML · 하루 100건 | 일 1회 | `/api/welfare` · 제도 카드 「공식 정보」 |
| **② 지자체 복지** (시·도, 시·군 자체사업) | 춘천시 발달재활 시 자체사업 · 창원시 달팽이관 수술비 | 한국사회보장정보원 「지자체복지서비스」 ([15108347](https://www.data.go.kr/data/15108347/openapi.do)) | ✅ XML · 하루 1,000건 | 실시간 | `/api/welfare?source=local` · 「지역 자체사업」 |
| **③ 시도교육청 특수교육** | 치료지원 · 방과후 · 통학 | 행정안전부 「공공서비스(혜택) 정보」 ([15113968](https://www.data.go.kr/data/15113968/openapi.do)) **+ 교육청 문서** | ⚠ **절반만** — 금액·구비서류·신청 시기는 API, **서식 번호·선정 절차는 문서에만** | API 실시간 / 문서 연 1회 이상 | `/api/welfare?source=gov24&org=…` · `Program.byRegion` |
| **④ 교육지원청** | 특수교육지원센터 연락처 | 교육청·교육지원청 누리집 | ❌ | 수시 (담당자 교체) | `Region.eduContact` (사람이 확인) |

**가장 큰 발견 — ③이 절반은 API로 된다.** 행안부 API에 시도교육청 특수교육 서비스가 금액·구비서류·신청기한까지
실려 있다. 실제로 확인한 교육청: 강원 · 경남(상세까지), 서울 · 부산 · 대구 · 인천 · 전남광주(목록). 나머지 9곳은 아직
불러 보지 않았다. 다만 **진단·평가 의뢰서 서식 번호와 선정·배치 절차**는 API에 없어 교육청 문서를 사람이 읽어야 한다.

## 4. 자동 수집에 대해 — 하지 않는다

| 막혀 있는 곳 | 근거 |
|---|---|
| 제주 · 충남 | robots.txt가 일반 크롤러 **전체 Disallow** |
| 대전 본청 · 충북특수교육원(sp.cbe.go.kr) | robots.txt 전체 Disallow |
| 광주 · 전남(jge.go.kr) | robots.txt 요청이 웹방화벽에 막힘 — 정책을 알 수 없음 |
| 인천 | 첨부 원본(`/upload/`) 차단 |
| 정부24(gov.kr) | `Disallow: /` — 화면 수집 대신 행안부 API를 쓴다 |

**RSS는 16곳 중 동작하는 곳이 0곳이다.** 게시판 목록 HTML은 대부분 읽히지만, 막힌 곳이 있고 형식이 제각각이다
(hwp · hwpx · pdf, 확장자와 실제 형식이 다른 곳도 있다 — 충남). 그래서 **교육청 문서는 사람이 정해진 시기에 확인한다.**
기관 협조를 받아 문서를 직접 받는 것이 장기적으로 맞다 (B2G 도입 조건으로 넣을 수 있다).

## 6. 새 지역을 열 때 순서

1. 행안부 API로 그 교육청 서비스 목록을 불러 치료지원 · 방과후 · 통학 ID를 찾는다 (`/api/welfare?source=gov24&org=○○교육청`)
2. 상세에서 금액 · 구비서류 · 신청 시기를 `Program.byRegion`에 넣는다. 원문에 없는 값은 비워 두고 「학교 확인」으로 적는다
3. 위 표의 운영계획 · 선정·배치 지침에서 **진단·평가 의뢰서 서식 번호**와 **기초조사 서류를 누가 쓰는지**를 확인해 `FORM_NO` · `FORM_SOURCE_BY_REGION`에 넣는다
4. 시·군 목록(`SIGUNGU`)과 교육지원청 연락처(`Region.eduContact`)를 넣는다
5. 그다음 `implemented: true`
