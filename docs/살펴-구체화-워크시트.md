| **낙상예방 재가환경지원** | ✅ 건보공단 | ✅ 100만 원 (본인부담 15%) | ✅ 생애 1회 | ✅ 장기요양 재가수급자, 낙상 위험 높음, 본인·가족 소유 주택 | ✅ 시설입소·병원입원·기초생활수급자·**아파트 거주자** | ✅ 공단 장기요양운영센터, 누리집 | ⬜ |

## 표 2. 위험요소 → 사업 매핑 (판정 규칙) ★

> 이게 AI 프롬프트의 설계도다. **같은 품목이 여러 사업에 있으면 어느 쪽이 유리한지 판정하는 것**이 "지원 최대화"의 핵심 로직이다.

| # | 위험요소 | 사진에서 보이는 것 | 연결 가능 사업 | 지원 품목 | 유리한 쪽 판정 |
|---|---|---|---|---|---|
| 1 | 욕실 손잡이 없음 | 변기 옆·샤워 부스에 손잡이 부재 | 낙상사업 / **복지용구** | 안전손잡이 | ⬜ **복지용구는 연 10개까지 매년** — 이쪽이 유리할 수 있음 |
| 2 | 미끄러운 바닥 | 욕실 타일, 물기 | 낙상사업 / **복지용구** | 미끄럼방지 매트·방지액 (복지용구 연 5개) | ⬜ |
| 3 | 현관·베란다 단차 | 문턱 | 낙상사업 | 문턱방지 경사로, 단차 축소 발판 | ⬜ 복지용구에 없음 → 낙상사업 |
| 4 | 야간 조명 부족 | 어두운 복도, 센서등 없음 | 낙상사업 | 조명 개선 | ⬜ |
| 5 | 바닥 장애물 | 전선, 발매트, 낮은 가구 | ⬜ (시공 불필요·안내만?) | — | ⬜ |
| 6~13 | ⬜ **13개 품목 전체 목록 확보 후 작성** | | | | |

> **⚠ 1순위 과제**: [복지부 보도자료](https://mohw.go.kr/board.es?act=view&bid=0027&list_no=1490828&mid=a10503000000) **붙임2 「서비스 품목별 시공내용」** hwpx 파일. 이게 없으면 이 표를 못 채우고, 못 채우면 데모도 못 만든다.

## 표 3. 수수료 설계

| 항목 | 결정 | 근거·주의 |
|---|---|---|
| **누가 내는가** | ⬜ 보호자(자녀) / 어르신 본인 | ⚖️ 업체에게 받으면 알선 금지 위반 |
| **언제 내는가** | ⬜ 신청 시 / **지원 확정 후** | 확정 후가 저항이 적다 |
| **얼마** | ⬜ | 정액 권장. % 방식은 "지원금 뜯는다" 인상 |
| **정액 vs 성공보수** | ⬜ | 복지 영역에서는 **정액이 방어하기 쉽다** |
| **무료 범위** | ⬜ 진단까지 무료 / 연결까지 무료 | 진단 무료면 진입장벽이 사라진다 |
| **독거·무연고 처리** | ⬜ | ⚠ **가장 중요.** 보호자가 없으면 누가 내는가? 여기서 사회문제 명분이 걸린다 |
| **환불 조건** | ⬜ | 지원 탈락 시 |

### ⚖️ 반드시 지킬 선

| | 판정 |
|---|---|
| 우리가 서류를 **대신 작성·제출**한다 | 🔴 **행정사법 위반 소지** (무자격 행정사 업무) |
| 소프트웨어가 **초안을 생성**하고 본인·요양보호사가 확인·제출 | 🟢 도구 제공 |

> 표현을 **"서류를 써드립니다" → "서류가 자동으로 채워집니다"**로 고정할 것.

## 표 4. 사용자 여정 (누가 무엇을 하는가)

| 2. 촬영 | ⬜ 요양보호사 / 사회복지사 / 보호자 | 집 안 촬영 | 사진 5~10장 | 30초 |

| 6. 신청 | ⬜ 본인·보호자 | 서류 확인 후 제출 | 신청 완료 | ⬜ |
| 7. 과금 | ⬜ | ⬜ | — | ⬜ |
